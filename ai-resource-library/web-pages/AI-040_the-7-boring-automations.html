Chapter 01: Why Boring Wins

The automations that make money aren't the flashy demos. They're the plumbing, the repetitive, unglamorous work that quietly drains a business. Nobody posts about it, and that's the opening. Here's why the boring stuff is the best thing you can sell.

Boring = recurring pain

Missed calls, slow quotes, no-shows, dead admin. These don't trend on X, but they bleed money every single day, which is exactly why businesses pay to fix them, every month.

Boring = recurring revenue

Unsexy problems don't get solved once and forgotten. They need monitoring, tuning and ownership, so a build fee turns into a retainer instead of a one-off.

Boring = easy to prove

The ROI is a number the owner already feels: jobs recovered, hours returned, chairs filled. You're not selling 'AI', you're selling money back.

Boring = same shape every time

Every one of the seven is a trigger, an AI judgement step, actions across the business's tools, and a human gate where it matters. Learn the shape once, reuse it forever.

The RuleDon't sell webhooks and JSON. Sell recovered revenue and reclaimed hours. The client never buys the workflow, they buy the outcome it produces, priced against the money it makes or saves them.

Chapter 02: The Operating Model

All seven run on the same skeleton. Learn it once and every build becomes a variation, not a fresh problem.

The Universal Stack

Trigger (call, form, message)
→
Orchestrator (n8n / Make)
→
AI brain (Claude / GPT)
→
Tools (CRM, Xero, SMS...)
→
Human gate (review & sign-off)

The Five-Phase Delivery Method

  1. Audit the bottleneckFind the one workflow bleeding the most time or money. Get the volume and the cost of doing it manually, that number sets your price.
  2. Map the workflowDraw trigger to decision to actions to gate before touching a tool. If you can't draw it, you can't build it.
  3. Build & integrateWire it in n8n / Make, add the LLM only where judgement is needed, connect the client's real tools.
  4. Test on real casesRun it against messy, real-world inputs, not the happy path. Edge cases are where trust is won or lost.
  5. Deploy behind a gateShip with a human review step, then monitor for drift. The retainer lives here.

Which Tool, When

n8nAI-agent-heavy builds, self-hosting and cost control at scale. The default for anything complex or data-heavy.
MakeThe fastest no-code visual builder. Reach for it when speed to a working scenario matters more than control.
VapiAnything voice or phone. The orchestration layer for STT, LLM, TTS and telephony in one.
HeuristicIf you can write the rules in 10 minutes, it's a workflow. If you'd need 50 if-statements and still miss cases, it's an agent. Only pay for an LLM where real judgement is needed.

Automation 01: Home Services & Trades (HVAC, Plumbing, Electrical, Roofing)

The Problem

  • Missed call = lost job
  • 62% of calls go unanswered
  • Best techs can't answer phones
  • No follow-up = no repeat work

The Fix: AI Voice Agent

  • Answers every call instantly
  • Triages emergencies, books the job
  • Syncs to ServiceTitan / Jobber
  • Captures lead details automatically
  • Chases unaccepted quotes
  • Handles out-of-hours calls

The Stack

Claude / GPTThe brain
ElevenLabsVoice
n8nBackend actions
ServiceTitan / JobberBooking

How It Flows

Inbound call (Twilio)
→
Vapi assistant (STT + LLM + TTS)
→
Tool calls (book / capture)
→
n8n backend (CRM + SMS)
Sells ToTrades doing $500k-$5m, owner-operator, 1-10 trucks, bleeding missed calls
Build Fee$2,500 - $5,000
Retainer$500 - $1,500/mo

How to Build It

  1. Get a number & connect telephonyBuy a Vapi number or import the business's existing Twilio line. Start as after-hours / overflow so it can't break live calls.
  2. Build the assistant in VapiPick the stack, Deepgram (STT), Claude or GPT-4.1 (LLM), ElevenLabs (TTS). Tune patience and interruption so it feels human, not robotic.
  3. Write the triage logicSystem prompt sets the role and the rules: emergency keywords (no heat, burst pipe, sparking) escalate or transfer; routine calls collect name, address, issue and book.
  4. Add tools via function callingDefine book_appointment, check_availability, capture_lead, send_sms. Each tool fires a webhook into n8n during the call.
  5. Wire the backend in n8nWebhook checks calendar / ServiceTitan availability, books the slot, sends an SMS confirmation, and logs the lead. Add a scheduled quote-chaser at 24h / 72h / 7d.
  6. Test latency, then deploySimulate calls in Vapi, target sub-800ms response, stress accents and interruptions. Go live after-hours first, then full overflow once it's solid.
Latency Is EverythingAbove around 1 second of delay the call feels robotic and callers hang up. Test relentlessly before going live, a slow agent loses more jobs than no agent.

Package & Sell It

Build fee: $2,500 - $5,000. Monthly retainer: $500 - $1,500/mo + minutes pass-through

The Pitch"You're losing jobs every week to calls nobody answers. This picks up every one, books it, and chases your dead quotes, one recovered job pays for the month."

Automation 02: Small Law Firms (Conveyancing, Immigration, PI, Family)

The Problem

  • Enquiries go cold overnight
  • Billable hours lost to drafting
  • Document work buries fee-earners
  • Slow, messy intake

The Fix: Intake-to-Draft Automation

  • 24/7 intake that qualifies leads
  • Conflict checks before humans look
  • Auto-fills the case system
  • Turns answers into first drafts
  • Firm-specific clause library
  • Human review built in

The Stack

Make / n8nOrchestration
Web formIntake
ClaudeAnalyse + draft
NotionMatter brief
Clio / AsanaCase + tasks
SlackReview alert

How It Flows

Intake form (new enquiry)
→
Conflict check (clear to proceed)
→
AI analyse + draft (facts + first draft)
→
File + assign (Notion / Clio + Slack)
Sells ToBoutique firms with 2-20 fee-earners and repeatable, high-volume matter types
Build Fee$4,000 - $10,000
Retainer$750 - $2,500/mo

How to Build It

  1. Build the intake formCapture matter type, parties, dates and a description. The firm drops the link on its site and Google Business so enquiries are caught 24/7.
  2. Trigger and conflict-checkForm submission fires the scenario. First step searches the firm's client list for the named parties and flags any conflict before a human spends a minute on it.
  3. AI analysis & extractionClaude classifies the matter, extracts key facts and dates, scores lead quality and flags urgency, turning a messy enquiry into structured data.
  4. Generate the first draftPass the facts plus the firm's own clause library (uploaded as reference) to Claude to produce a first-draft letter or agreement, clearly stamped DRAFT.
  5. File it and assignCreate a Notion / Clio matter brief, open a review task in the case system, and attach the draft so everything lives in one place.
  6. Human review gateSlack the fee-earner: new matter, draft ready. Nothing leaves the building without a qualified person signing off, that gate is the whole point.
This Drafts, It Does Not AdviseLegal output must be reviewed by a qualified person. Build the human gate in by default and never let a draft auto-send. You're saving hours, not replacing judgement.

Package & Sell It

Build fee: $4,000 - $10,000. Monthly retainer: $750 - $2,500/mo monitoring + tuning

The Pitch"Every enquiry answered in minutes, conflict-checked, with a first draft already waiting. Your fee-earners only touch the high-value 20%, the rest is done before they sit down."

Build Fee$3,500 - $9,000

How to Build It

  1. Connect XeroStand up the official @xeroapi/xero-mcp-server with OAuth2 client ID and secret, or hit the Xero API directly from n8n. Scope it to invoices, contacts and reports.
  2. Build the document intakeA dedicated inbox or upload that n8n watches. OCR plus Claude extract supplier, date, amount, tax and category from messy PDFs and phone photos.
  3. Clean & structureAI normalises the data and matches it to the chart of accounts. Anything ambiguous is flagged for a human instead of being guessed, that's what keeps it trusted.
  4. Write to XeroPush structured bills, invoices and contacts into Xero through the MCP tools. No more re-keying receipts by hand.
  5. Auto-chase clientsA scheduled workflow spots missing documents and unreconciled items, then runs a polite branded email / SMS chase until the client actually sends them in.
  6. Auto-draft advisory & firm opsMonthly, pull Xero reports via MCP and have Claude draft a plain-English management report for review. Automate the firm's own onboarding and deadline reminders too.
Keep a Human Sign-OffIt's financial data. The AI categorises, cleans and drafts, the accountant reviews and signs off. Flag-don't-guess on anything ambiguous and you'll keep the trust that sells the service.

The Pitch"Stop chasing clients and re-keying receipts. Clean data flows into Xero automatically and your advisory reports are drafted for you, you just review, sign and bill."

Automation 04: Dental & Medical Practices (Dental, Aesthetics, Physio, Clinics)

The Problem

  • No-show = empty chair = lost money
  • Front desk can't keep up
  • Lapsed patients forgotten
  • Patients won't wait on hold

The Fix: AI Comms + No-Show System

  • Multi-touch reminders (text, email, voice)
  • Confirmations plus waitlist fill
  • Flags likely no-shows early
  • 24/7 self-serve booking
  • Recall and reactivation campaigns
  • Hands clinical questions to staff

The Stack

n8nOrchestration
Twilio SMSMessaging
VapiVoice reminders
Email (Resend / SendGrid)Email channel
PMS (Dentrix / EHR)Schedule source
ClaudeIntent routing

How It Flows

Schedule (from the PMS)
→
Reminder cadence (email + SMS + voice)
→
Handle replies (confirm / reschedule)
→
Waitlist backfill (fill the gap)
Sells ToPractices losing 10-15% of appointments to no-shows with a stretched front desk
Build Fee$3,000 - $7,000
Retainer$500 - $1,500/mo

How to Build It

  1. Connect the schedulePull appointments from the PMS (Dentrix, Eaglesoft, or the practice's EHR). n8n holds the source of truth for who needs reminding and when.
  2. Build the reminder cadenceThe proven sequence: email 72h out, two-way SMS 24h out with a confirm / reschedule link, then an AI voice call or SMS 2h out. Multi-channel cuts no-shows about 2x vs one channel.
  3. Handle the repliesInbound SMS or voice goes to Claude, which classifies intent, confirm, cancel, reschedule or question, and updates the schedule automatically.
  4. Waitlist backfillThe moment someone cancels, the system texts the waitlist in priority order. First to accept gets the slot and the PMS updates, gaps fill in minutes, not days.
  5. No-show risk + recallScore patients on history and response, and add an extra touch to high-risk ones. Run hygiene recall at 30 / 14 / 7 / 1 days and a reactivation sequence for lapsed patients.
  6. Clinical guardrail + go liveAny clinical or medical question is never answered by AI, it's routed straight to a human. The system handles booking and admin only.
PHI Is Not OptionalHealthcare data needs HIPAA-eligible tooling, signed BAAs and encryption (UK GDPR + clinical governance over here). The AI never gives clinical advice, booking and reminders only.

Package & Sell It

Build fee: $3,000 - $7,000. Monthly retainer: $500 - $1,500/mo easy ROI

The Pitch"Cut no-shows below 5%, fill cancellations in minutes and reactivate lapsed patients, without hiring another person for the front desk. Recovered chairs pay for it many times over."

Automation 05: Recruitment & Staffing (Agencies, In-house talent teams)

The Problem

  • Slow sourcing = thin pipeline
  • Best candidates gone in days
  • Admin eats the week
  • More CVs, harder to read

The Fix: AI Sourcing + Screening Engine

  • Mines your own database first
  • Plain-language search, no Boolean
  • Parses and scores CVs
  • Validates skills, not keywords
  • Multi-channel outreach sequences
  • Auto-schedules interviews

The Stack

n8nOrchestration
Bullhorn / LoxoATS / CRM
ClaudeParse + score
Vector DBSemantic search
Email + LinkedInOutreach
Cal.comScheduling

How It Flows

Job brief (plain English)
→
Search own DB (semantic match)
→
Parse + score (skills, not keywords)
→
Outreach + book (sequence + calendar)
Sells ToAgencies sitting on a big, underused candidate database; flooded in-house TA teams
Build Fee$4,000 - $12,000
Retainer$1,000 - $3,000/mo

How to Build It

  1. Index the databaseExport the firm's existing candidate database and embed every CV into a vector store. Now you can search by meaning, not by fragile Boolean strings.
  2. Plain-language searchThe recruiter types the role in plain English and semantic search surfaces the best existing candidates first, the cheapest placement is one already in your database.
  3. Parse & structure CVsClaude extracts structured fields (titles, dates, skills, seniority) from any CV format, turning the unreadable pile into comparable, searchable data.
  4. Score against the briefThe AI scores each candidate on the real requirements, validating demonstrated skills over keyword-stuffing, and returns a ranked shortlist with reasons attached.
  5. Outreach sequencesGenerate personalised multi-channel sequences (email + LinkedIn) per candidate, throttled and tailored so it reads like a recruiter wrote it, not a blast.
  6. Auto-schedule + write backInterested replies get a booking link; the interview lands in the recruiter's calendar and every action writes back to the ATS so nothing is double-worked.
Score, Then Let Humans DecideScreening models can carry bias. Keep a recruiter in the loop on every shortlisting decision and audit the scoring. The AI ranks and surfaces, people make the call.

Package & Sell It

Build fee: $4,000 - $12,000. Monthly retainer: $1,000 - $3,000/mo + monitoring

The Pitch"Fill faster from the database you already paid for. Plain-language search, scored shortlists and outreach on autopilot, your recruiters spend the week placing, not reading CVs."

The Problem

  • Ingests and pre-fills ACORD data
  • Side-by-side coverage comparison
  • Auto-builds client proposals
  • Integrates with the AMS
  • Follows up on the client's channel

How It Flows

Docs in (ACORD / dec pages)

Extract + validate (structured fields)

Sells ToIndependent P&C agencies, commercial-heavy, small team that can't scale on hiring
Build Fee$5,000 - $15,000
Retainer$1,000 - $3,500/mo

How to Build It

  1. Build the smart intakeOne form or doc-drop where the client uploads their existing policy or ACORD. Conversational intake fills the gaps, forms convert terribly, so make it effortless.
  2. Extract the ACORD dataDocument AI plus Claude pull structured fields from ACORD 125 / 126, dec pages and loss runs at roughly 95% on clean PDFs, low-confidence fields get flagged for review.
  3. Pre-fill the raterPush the validated data into a comparative rater (EZLynx, Tarmika) so it's one entry across every carrier, not re-keying into each portal.
  4. Normalise the quotesPull the returned carrier quotes and have the AI build a clean side-by-side comparison, limits, deductibles, price and coverage gaps in one view.
  5. Auto-build the proposalGenerate a branded client proposal with the recommended option and the reasoning, as a draft for the producer to review, never auto-sent.
  6. Write to the AMS + follow upLog the submission, quotes and documents to the AMS for the E&O trail, then run an automated follow-up sequence on the client's preferred channel.
A Licensed Producer Must AdviseAI speeds the quote, it does not decide suitability or bind coverage. Keep producer review, mind TCPA / consent and state DOI rules, and document everything for E&O. Underwriting stays with the carrier.

Package & Sell It

Build fee: $5,000 - $15,000. Monthly retainer: $1,000 - $3,500/mo highest-value build

The Pitch"Cut quote time from hours to minutes. One entry, every carrier, a clean comparison and a finished proposal, your producers stop re-keying and start advising and closing."

How to Build It

  1. Open the channelsWeb chat, SMS and voice all flow into one n8n inbox so tenants reach you however they prefer, around the clock.
  2. Answer the routineClaude handles routine questions, rent due, how-to, office hours, from a knowledge base, clearing the noise off the team's desk.
  3. Triage maintenanceEach request is classified by type (plumbing, electrical, HVAC, structural, pest) and urgency, collecting details and photos up front.

Humans Own Real RiskKeep emergencies on a fast human path and leave disputes and evictions to people. The AI clears the routine noise so the team can focus on what actually needs judgement.

Four Pricing Principles

Price to value, not to effort

A build that removes $60k of annual cost is cheap at $10k. Pricing by 'number of scenarios' undercharges every time.

Build fee + retainer

Charge to build it, then charge monthly to own it, monitoring, fixes and tuning. Some waive the build fee for a 6-month retainer commitment.

Pass usage through

Voice minutes, SMS and API tokens are the client's cost, not yours. Keep them separate so your retainer stays pure margin.

Position as an AI employee

You're replacing a function, not selling a plugin. Price against the salary or revenue it stands in for, and add an outcome bonus on top of the base if you're confident.

Chapter 11: Your First 30 Days

The whole stack costs less than a coffee habit to start. The constraint is never the tools, it's picking one thing and actually shipping it.

Accounts to Open

  • n8n Cloud from ~$20/mo or self-host free. Your orchestration backbone.
  • Vapi Voice agents. Bring-your-own keys, pay providers directly, low markup.
  • Twilio Phone numbers and SMS for voice and reminder builds.
  • Anthropic API Claude for the judgement, drafting and extraction steps.
  • Make Optional, the fast no-code alternative for simpler scenarios.

The First Three Moves

  1. Pick one automation, one industryDon't build a menu. Master a single playbook for a single niche so you can sell it again and again without re-learning.
  2. Build it once, cheap, for a first clientTrade a low price (or free) for a real deployment, a case study and a testimonial. That proof is worth more than the first cheque.
  3. Sell the outcome, then repeatTake the recovered-revenue number to the next ten identical businesses. Same build, same pitch, full price.
TruthEverything in this guide can be built by one person with these accounts and a weekend per automation. The businesses that need them won't build them themselves, that gap is the entire opportunity.

Seven automations, one repeatable stack, and a market of businesses that feel the pain every day but will never build the fix themselves. Pick one. Build it this week. Sell it.
