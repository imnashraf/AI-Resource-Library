PostHog + Claude Code Setup Guide

Max Johnson@maxjohnscn

PostHog + Claude Code: Analytics, A/B Testing & Self-Optimising Landing Pages.

This guide gets you from a landing page with zero tracking to a fully connected, A/B-testing setup that Claude can read and optimise. Everything here runs on PostHog's free plan. Follow the steps in order, the whole setup takes about 15 minutes.

What you will have when this is done:

  • PostHog fully installed and tracking on your landing page
  • Custom event tracking, button clicks, scroll depth, form submissions
  • Claude reading your live PostHog data to analyse what is working
  • An A/B split test running on your hero section, tracked automatically

PostHog, Free Analytics That Connects to Claude Code. PostHog is a free analytics platform. Go to posthog.com and create a free account before starting. It tracks everything happening on your site, where people click, where they drop off, how far they scroll. Once connected to Claude Code, Claude can read all of that data and act on it directly.

TIP: The free plan covers everything in this guide. No paid account needed. PostHog has a genuinely useful free tier.

You also need a landing page that was built or can be opened inside Claude Code.

Step 01, Create Your PostHog Account, posthog.com

Go to posthog.com and sign up for free. Once you are in, create a new project for your landing page. You will need your Project API Key from the PostHog dashboard, find it under Settings then Project. Keep the tab open.

NOTE: Your Project API Key starts with phc_ followed by a long string. Claude Code will ask for this when it installs PostHog, paste it in when prompted.

Step 02, Install PostHog via Claude Code, Claude handles everything

Open Claude Code and point it at your landing page project folder. Paste the prompt below exactly as written. Claude will research the right installation method for your stack, install PostHog, configure it, and verify events are firing, all on its own.

$ Claude Code, paste this to install PostHog Research how to install PostHog on this repository Install and configure it Verify that events are being sent to the PostHog dashboard

TIP: Claude figures out the right method for your stack automatically, plain HTML, React, Next.js or anything else. You do not need to touch the code yourself.

NOTE: Once the prompt finishes, go to your PostHog dashboard and click around your page in a browser. You should see events appearing in the Live Events view in real time.

Step 03, Set Up Custom Event Tracking, Know exactly what people are doing

Basic PostHog gives you page views. Custom events give you the things that actually matter, which buttons people click, how far they scroll before leaving, whether they hit your form.

$ Claude Code, paste this to add custom tracking Set up posthog custom event tracking on this site. Track: button clicks with the button text as a property, form submissions with the form scroll depth at 25% 50% 75% and 100% and outbound clicks. Use descriptive event names. Verify events appear in the PostHog dashboard.

TIP: After this runs, click every button on your page and scroll through it fully. Go to PostHog > Live Events and confirm each action is showing up with the right name and properties.

Step 04, Connect Claude to Your PostHog Data, Your analytics advisor

Now you set Claude up as a connected analytics advisor. Instead of reading charts yourself, Claude reads your live PostHog data and tells you exactly what to fix, and writes you the Claude Code prompt to implement each change.

Open Claude Code with your landing page folder selected. Paste this as your opening prompt for a new session:

$ Claude Code, paste this to set up the analytics advisor You are a website analytics advisor connected to PostHog. When I ask about my site, pull real data from PostHog. Analyse event patterns, conversion rates, and user drop off points. Identify what is working, and what is underperforming. When you recommend a change, write a specific prompt i can paste into Claude code to implement it. Always back recommendations with actual PostHog data, not assumptions.

Once this is running you can ask Claude things like:

  • Where are people dropping off my page?
  • Which CTA button is getting the most clicks?
  • What section has the highest scroll drop-off?
  • What percentage of visitors are reaching my form?
  • What should I change first to improve conversions?

TIP: Every recommendation Claude gives will come with the exact Claude Code prompt to implement it. Paste it in, Claude Code makes the change, the data starts updating.

Step 05, Set Up an A/B Split Test, Let the data decide

Run two versions of your landing page at the same time and let PostHog tell you which one converts better. Claude Code builds both versions and sets up the split using PostHog feature flags automatically.

$ Claude Code, paste this to run the A/B split test Set up an A/B split test on the hero section using PostHog feature flags. Keep the current version as the control. Create one variant with a different headline and CTA button text. Track clicks on the primary CTA as conversion goal. Split traffic 50/50. Both variants should look identical except for the copy.

TIP: Once it is running, go to PostHog > Experiments to watch results build. When one variant is clearly winning, tell Claude Code which version won and ask it to make that the default.

NOTE: The split test uses PostHog feature flags, PostHog randomly assigns each visitor to control or variant and tracks which group converts better.

Your Landing Page Is Now Learning

With all five steps done, you have a landing page that tracks its own performance, lets Claude analyse the data, and can run split tests on any section. The next step is to use it.

Check in with your PostHog analytics advisor every few days and ask it what the data is showing. When it recommends a change, paste the prompt into Claude Code. Let the test run for at least a week before calling a winner.

TIP: The more traffic your page gets, the faster the data becomes useful. Even with low traffic, scroll depth and click patterns will show you where the page is losing people within the first few days.

PostHog is free at posthog.com. Everything in this guide works on the free plan with no card required.
