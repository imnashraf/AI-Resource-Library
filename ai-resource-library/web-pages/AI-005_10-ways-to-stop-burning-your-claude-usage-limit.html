10 Ways to Stop Burning Your Claude Usage Limit

Max Johnson @maxjohnscn

Most people burning through their Claude usage limit are doing it completely by accident. Claude re-reads the entire conversation every single time you send a message. The longer the chat, the more it costs. These 10 tips will cut your usage significantly, and some of them take less than two minutes to set up.

1, Use /compact to Compress a Long Chat

When a conversation gets long, the token cost of each new message snowballs fast. The /compact command synthesises the entire chat into a condensed summary and replaces the full history with it. You keep context but cut the overhead dramatically.

How to do it:

  1. Open a long-running Claude chat. Navigate to any conversation that has been going for more than 15 to 20 messages.
  2. Type the compact command. In the message box, type the forward slash followed by the word compact and hit enter.
  3. Continue in the same chat. Claude synthesises the conversation into a summary recap. You can carry on from there without restarting.
// Type this into the Claude message box
/compact
// Claude will summarise and compress your full chat history
// You keep context. You lose the dead weight.

TIP: Use /compact before a chat gets painful, not after. Once you are past 30 messages it is already costing you. Run it at 15 to 20 as a habit.

2, Edit Your Prompt Instead of Sending a Follow-Up

When Claude misses the mark, most people type a correction and send it as a new message. That adds the bad response and your correction to the conversation history. Claude then re-reads all of it next time. Instead, click edit on your original message, adjust it, and regenerate. The old response gets replaced, not added.

How to do it:

  1. Hover over your message. Find the message you want to change. Hover over it to reveal the edit option.
  2. Click edit and update your prompt. Rewrite or adjust what you originally sent.
  3. Hit send to regenerate. Claude regenerates from that point. The old response is gone from the thread entirely.

WHY IT MATTERS: Over 10 rounds of back-and-forth editing, using edit instead of follow-up messages can cut token use by 80 to 90 percent. The history stays lean.

3, Start a Fresh Chat Every 15 to 20 Messages

Your first message costs around 200 tokens. By message 30, that same simple question costs 50,000 or more. The fix is simple: when a chat gets long, ask Claude to summarise where things are up to, open a new chat, paste the summary in, and carry on.

How to do it:

  1. Ask Claude to summarise at message 15 to 20. Send this message: Summarise everything we have covered so far in this chat, including any key decisions, outputs, and context I need to continue.
  2. Copy the summary. Select and copy the full summary Claude produces.
  3. Open a new chat and paste it in. Start fresh. Paste the summary as the first message and continue from there.
// Paste this into Claude when ready to reset:
Summarise everything we have covered so far in this chat,
including any key decisions, outputs, and context I need to
continue in a new conversation.

4, Batch Your Questions into One Message

Three separate messages means three separate context loads. One message with three questions means one. List your questions together and ask Claude to answer them all. The answers are usually better too because Claude sees the full picture before it responds.

How to do it:

  1. Group your questions before sending. Instead of sending each question as it comes to you, write them all out first.
  2. Format them as a numbered list. Use simple numbering. Tell Claude you have a few questions and to answer them all.
  3. Send as one message. One send, one context load, three answers.
// Example: instead of three messages, send one
I have a few questions. Please answer all of them:
1. [Question one]
2. [Question two]
3. [Question three]

5, Upload Recurring Files to Projects

If you are sending the same PDF, brief, or document across multiple chats, Claude is re-counting those tokens every single time. Projects cache your files so they do not cost tokens on each new conversation. Upload once, stop paying every time.

How to do it:

  1. Open or create a Project in Claude. Go to claude.ai and click Projects in the left sidebar. Create a new one or open an existing one.
  2. Upload your recurring documents. Add any files you use regularly. Briefs, brand guidelines, templates, reference docs.
  3. Start all relevant chats inside that Project. Every conversation inside the Project has access to those files without re-uploading them.

TIP: Projects are also where Memory and User Preferences apply automatically. If you are not using Projects yet, this single change will save you more tokens than almost anything else on this list.

6, Set Up Memory and User Preferences

Every conversation you start without context burns 3 to 5 messages just re-explaining who you are and how you work. Go to Settings, then Memory and User Preferences, and store it once. Claude carries it into every chat automatically.

How to do it:

  1. Go to Settings. In Claude.ai, click your profile icon or name in the bottom left and open Settings.
  2. Find Memory and User Preferences. Look for the Memory section and the User Preferences tab inside Settings.
  3. Write in your context once. Describe who you are, how you work, your tone preferences, your role. Claude will read this at the start of every new chat.
// Example User Preferences entry:
I am a founder running an AI agency called Briix based in Manchester.
I build and create content about AI tools. Write in British English.
Keep responses concise and direct. No bullet points unless I ask.
When writing content, match the voice in my Project instructions.

WHAT THIS REPLACES: The usual first 3 to 5 messages of every chat where you re-explain your role, preferences, and context. Stored once. Never repeated.

7, Keep Your System Prompts Tight

If you use a Project with a system prompt (the instructions you write in the Project Knowledge section), that prompt gets loaded into every conversation. A bloated system prompt with 2,000 words of context you never actually need is costing you tokens on every single message, in every chat, forever.

How to do it:

  1. Open your Project and review the instructions. Go to your Project and look at the instructions or knowledge you have set.
  2. Cut anything Claude does not need every session. If it is context that only applies to specific tasks, remove it from the Project instructions and paste it in when you actually need it.
  3. Aim for under 500 words in your standing instructions. Lean instructions. Essential context only. The rest lives in your documents and you reference it when needed.

WATCH OUT: Project instructions are loaded on every message in every chat inside that Project. A 3,000 word instruction set running across 50 chats a week adds up fast.

8, Use the Right Model for the Right Task

Claude Sonnet and Claude Haiku are lighter, faster models. Claude Opus is the most powerful but also the most expensive on token usage. If you are using Opus for tasks that do not need that level of reasoning, you are burning usage on a sledgehammer when a normal hammer would do.

When to use which:

  1. Claude Haiku, Quick tasks. Summarising short documents. Simple Q and A. Drafting short responses. Fast turnaround with low token cost.
  2. Claude Sonnet, Most everyday work. Longer documents, content creation, code, research. The best balance of quality and usage.
  3. Claude Opus, Complex reasoning, nuanced analysis, tasks that genuinely need the highest intelligence. Not for everyday use if you are watching usage.

TIP: On claude.ai, you can switch models from the dropdown at the bottom of the chat. Get into the habit of matching the model to the task instead of always defaulting to the most powerful one.

9, Ask for Shorter Outputs by Default

Claude defaults to thorough. If you ask a question, it will often give you a full essay when a paragraph would do. That essay is tokens coming back to you, and those output tokens count toward your usage. Tell Claude how long you want the answer to be.

How to do it:

  1. Set a length instruction in your User Preferences. Add a line like: Keep answers concise unless I ask for detail. This applies globally.
  2. Specify length per request when it matters. Add a word count or format instruction to the end of your prompt.
  3. Ask for bullet points for factual answers. Bullets force Claude to be concise. A 500-word explanation becomes 5 crisp lines.
// Add length control to any message:
Answer in 3 sentences or fewer.
// Or in your User Preferences:
Default to brief, direct answers. I will ask for detail when I need it.

10, Do Not Paste Content You Already Have in the Project

If a document is already uploaded to your Project, do not paste its content into the chat as well. You are double-loading it. Reference it by name instead. Claude already has access to it. Pasting it in again means counting every token twice.

How to do it:

  1. Check what is already in your Project Knowledge. Before uploading or pasting, review what is already stored in the Project.
  2. Reference documents by name, not by pasting. Instead of pasting a full document in, say: Using the brand guidelines document in this Project, do the following.
  3. Only paste in what is not already stored. If it is new content that will not be reused, pasting is fine. If it is something you use regularly, it belongs in the Project.

QUICK TEST: Ask yourself before pasting: will I need this document again in another chat? If yes, upload it to the Project instead of pasting it in again.
