Turn Any PDF Into a Claude Skill

Drop any of Max's free guides into Claude and get a working skill that runs on command in under a minute.

Why It Matters

Most people read a guide, try to remember the steps, and then half-improvise when they actually need it. Turning a PDF into a Claude skill means Claude remembers the whole guide for you and runs every step correctly, every time, without you having to think about it.

Chapter 01: What a Claude Skill Actually Is

A Claude skill is not a saved prompt you copy and paste. It is a set of instructions that Claude has already read and internalized, so it can follow them automatically the moment you ask.

When you upload a guide PDF to a Claude Project and tell Claude how to use it, Claude treats the guide as its own operating manual. It knows the steps, the order, the examples, and the expected output. You do not need to paste anything. You just tell Claude to run the skill and it does.

Here is what that means in practice:

What Claude Reads From the PDF
  • Every step and instruction
  • All prompts and examples
  • Tips, callouts, and caveats
  • The order everything happens in
  • What the output should look like
What Claude Can Then Do
  • Walk you through each step live
  • Generate the prompts for you
  • Adapt the process to your context
  • Flag when something is missing
  • Produce the final output directly
The Key Difference

A saved prompt tells Claude what to do once. A skill tells Claude what to do every time, in the right order, with the right logic baked in. The guide becomes behaviour, not a reference document you have to re-read.

Chapter 02: The Conversion, Step by Step

You need three things: the PDF, a Claude account, and one prompt. Here is the full process.

  1. Download the PDF guide you want to convert. Any of Max's free guides work. Save it somewhere easy to find on your device.
  2. Open Claude and start a new chat. If you are on a paid plan, open or create a Project first (covered in Chapter 03). If you are on the free plan, you can still use this method in a single chat session.
  3. Upload the PDF using the attachment button, then paste the conversion prompt below and send it.
I am uploading a guide PDF. I want you to read the entire guide carefully and treat it as a skill you will now run for me.

Once you have read it, confirm that you understand the guide's purpose, the steps it covers, and what the final output looks like.

Then ask me for the first piece of information you need to begin running the skill.

Do not summarise the guide back to me. Just confirm you have read it and start the process.
Free Plan Note

If you are on Claude's free plan, you can still use this method but the skill will only last for that one chat session. When you close the chat and start a new one, Claude will not remember the guide. To make the skill permanent and available across all future chats, you need a Pro, Max, or Team plan so you can use Projects. If you are on the free plan, re-upload the PDF each time you want to run the skill.

Chapter 03: Saving It So It's Always Ready

A one-session skill is useful. A permanent skill you can trigger from any chat is a different thing entirely. To make that happen, you use Claude Projects.

Projects let you attach files and instructions that persist across every conversation inside that project. Upload the guide once and Claude will have it available every time you open a chat in that project, without you needing to re-upload anything.

Here is how to set it up:

1
Create a Project in Claude

In the Claude sidebar, click "Projects" and then "New Project". Give it a name related to the guide you are converting, for example "Cold Outreach Skill" or "Content Repurposing Skill". This project will be the home for that skill going forward.

Pro · Max · Team only
2
Upload the PDF to the Project's knowledge

Inside the Project, find the "Knowledge" or "Files" section and upload your PDF guide. Claude will read and index the entire document. It becomes part of the project's permanent context, available in every chat you open inside that project.

3
Add the conversion prompt to Project Instructions

In the Project settings, paste a short instruction telling Claude how to behave. Something like: "You have been given a guide PDF in your knowledge. When I ask you to run the skill, follow every step in the guide exactly, in order, asking me for the information you need at each stage." This instruction fires automatically every time you start a chat in this project.

4
Open a chat and trigger it with one sentence

You do not need to paste any prompt or re-upload anything. Just open a new chat inside the project, type your trigger sentence, and Claude will pick up the guide from the project knowledge and start running the skill immediately.

Chapter 04: Triggering Your Skill

Once the skill is saved inside a Project, activating it takes one sentence. Here are three trigger formats depending on what you want Claude to do.

To run the full skill from the beginning:

Run the [guide name] skill. Start from step one and ask me for what you need.

To jump to a specific part of the guide:

Run the [guide name] skill. Skip to the section on [topic] and start from there.

To get the output directly without being walked through each step:

Run the [guide name] skill. Here is all my context: [paste your details]. Produce the final output now.
Tip

The more specific your trigger, the better Claude performs. If the guide has named sections or chapters, use those exact names in your trigger. Claude will navigate directly to the right part of the guide instead of starting from scratch.

Stack multiple guides

You can upload more than one guide to the same Project. If you have three guides covering different parts of a workflow, upload all three. Then trigger them in sequence in a single chat session.

For example, if you have a research guide, a writing guide, and an outreach guide, you could run all three back to back in one project chat and have Claude carry the output from each step into the next. This turns a collection of individual guides into a full end-to-end workflow that Claude runs for you without you having to manage the handoffs manually.

Chapter 05: When It Doesn't Work

Most issues come from one of four places. Here is what to check and how to fix each one.

01
Claude gives a generic response instead of running the guide

This usually means Claude did not receive a clear instruction to treat the PDF as a skill. Go back to the conversion prompt in Chapter 02 and send it again explicitly. Make sure the PDF is still attached and visible in the chat before you send the prompt. If you are inside a Project, check that the Project Instructions include a line telling Claude to run the skill when prompted.

02
Claude says it can't see the file or doesn't know about the guide

If you are in a direct chat, you need to re-upload the PDF. It is not saved between sessions on the free plan. If you are inside a Project, go to the Project settings and check that the PDF is listed under Knowledge or Files. Sometimes uploads fail silently. Delete the file and re-upload it, then start a new chat inside the project.

03
Projects are not available in your Claude

Projects are only available on Claude Pro, Max, and Team plans. If you are on the free plan, you will not see Projects in the sidebar. Your options are: upgrade to a paid plan to get persistent skills, or re-upload the PDF guide at the start of each session and use the conversion prompt each time. The skill will work just as well within that session, it just will not persist.

04
Claude loses track or goes off-script partway through

This happens in long sessions when Claude's context window fills up. The fix is to remind Claude where it is. Type something like: "You are running the [guide name] skill. We just finished step [X]. Continue from step [X+1] and follow the guide exactly." If the session has gone very long, it is often faster to start a fresh chat in the project and trigger the skill from the point where you left off using the context you already have.
