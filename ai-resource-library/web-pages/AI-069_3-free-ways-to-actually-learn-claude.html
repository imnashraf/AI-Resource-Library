Chapter 01: Why This Is Worth Your Time

Dario Amodei, the CEO of Anthropic, has spent the last year warning publicly that AI is set to concentrate wealth and power faster than almost anyone is prepared for. He has described the shift happening "almost overnight" and "almost by accident," and has floated the idea that AI could mint the world's first trillionaires while leaving a lot of people behind if the gains aren't shared.

Note

This is a summary of several separate statements Amodei has made in essays and interviews through 2026, not one single quote. The underlying point, that AI's benefits could concentrate quickly among a small number of people and companies, is something he has repeated consistently.

That's the uncomfortable backdrop. The more grounded, practical version of it is this: most people who use Claude are only using a small fraction of what's actually available to them, for free, from Anthropic directly. They type into the chat box and stop there.

The people pulling ahead right now aren't necessarily smarter or more technical. They've just gone one layer deeper: they've taken the free training, installed the tools that extend what Claude can do, and built a small stack of specialist agents that do more of the work for them. None of it costs anything to start.

Chapter 02: Claude Academy, Anthropic's Own Free Course Library

Anthropic has literally built free courses to teach people how to get the most out of Claude. The platform is called Claude Academy, and it sits at academy.claude.com. It covers everyday use in Claude.ai, hands-off work in Claude Cowork, building with Claude Code, team workflows in Claude Tag, and developer work on the Claude Platform (the API, Console, and MCP).

Note

This platform used to be called Anthropic Academy. It was rebuilt and rebranded as Claude Academy in August 2026, with a much larger library of courses, tutorials, and use cases than the earlier version. If you see older articles calling it a "13-course" or "20-course" catalogue, that's the previous version.

What makes it worth using

  • Every course is free and self-paced, built directly by the team behind Claude, not a third party reinterpreting the docs
  • You can read public lessons without signing in; signing in with a Claude account saves your progress and unlocks quizzes and a completion badge
  • Alongside full courses there are shorter tutorials and role-based "use cases," so you're not always committing to an hour-long course just to answer one question
  • There's a dedicated AI Fluency track built around a "4D" framework, delegation, description, discernment, and diligence, for people who need to think about AI use more broadly, not just click buttons
If you're non-technical

Start with "Claude 101," then "AI Capabilities and Limitations." Both assume zero prior experience.

If you build or code

Start with "Claude Code 101," then move into the Model Context Protocol (MCP) courses when you're ready to connect Claude to real tools.

Chapter 03: The Official Claude Skills Library, Anthropic's Own Plug-Ins for Claude

A Skill is a folder of instructions, scripts, and resources that Claude loads on demand to get better at a specific job, whether that's producing a document in your brand style, following your organisation's exact workflow, or handling a niche technical task. Think of them less as plug-ins in the app-store sense, and more as detailed, reusable briefing packs Claude reads before it starts work.

Anthropic publishes its own official set at github.com/anthropics/skills. It's split into two parts: the document skills (PDF, Word, PowerPoint, Excel) that power Claude's own file-creation features under the hood, and a broader set of example skills spanning creative and design work, technical and development tasks, and enterprise workflows like internal comms and branding.

Warning

The repository itself is free and public to browse. Actually using pre-built skills, or uploading your own, inside Claude.ai currently requires a paid plan (Pro, Max, or Team) with code execution switched on. In Claude Code, skills work regardless of plan once installed as a plugin.

Why this one matters

  • These are the same building blocks that power features like document creation inside Claude.ai, so browsing them is a genuinely useful way to see how Anthropic itself structures instructions for Claude
  • Each skill is self-contained in its own folder with a single SKILL.md file, which makes them easy to read, copy, and adapt even if you've never built one before
  • If you've ever wanted Claude to consistently follow your own brand guidelines, tone of voice, or internal process, this is the exact mechanism, and the official repo is the cleanest set of examples to learn the pattern from

Install (run inside Claude Code to install the official example skills as a plugin)

/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

Chapter 04: Awesome Claude Code Subagents, 150+ Free Specialist Agents for Claude Code

This one lives at github.com/VoltAgent/awesome-claude-code-subagents, a free collection of 150+ subagents you can add to Claude Code. Each subagent is a specialised system prompt built for one type of work, a security auditor, a database optimiser, a technical writer, and so on, with its own tool permissions and its own isolated context window so it doesn't clutter your main conversation.

How it's organised

The agents are grouped into ten categories: Core Development, Language Specialists, Infrastructure, Quality & Security, Data & AI, Developer Experience, Specialised Domains, Business & Product, Meta & Orchestration, and Research & Analysis.

  • Smart model routing: Each subagent is pre-set to a model, Opus for deep reasoning like security audits, Sonnet for everyday coding, Haiku for quick tasks like docs or dependency checks.
  • Granular permissions: Read-only agents like reviewers get Read, Grep, and Glob only. Agents that write code get Bash and Edit too. You can adjust this yourself.

Install (run inside Claude Code; swap "voltagent-lang" for any category plugin, or install agents individually)

claude plugin marketplace add VoltAgent/awesome-claude-code-subagents
claude plugin install voltagent-lang

Chapter 05: Official vs Community, Know the Difference Before You Build on Any of Them

Two of these three tools are built and maintained by Anthropic. The third is a well-regarded, actively maintained community project, but it is not an Anthropic product, and it's worth being clear-eyed about what that means before you rely on it for anything serious.

Warning

The subagent repo is MIT-licensed and openly says it doesn't audit or guarantee the security or correctness of every submission. That's normal for open-source, community-maintained collections, not a red flag exactly, but it does mean you should read a subagent's instructions before installing it, the same way you'd review any code you didn't write yourself.

None of this means avoid the community tool. It's one of the most-starred resources of its kind for a reason. It just means treat "official Anthropic" and "community-built" as two different trust levels, and choose accordingly for anything that touches sensitive data or production systems.

Chapter 06: How To Actually Use All Three

  1. Start with Claude Academy: Pick the track that matches your role. "Claude 101" if you're new, "Claude Code 101" if you build. Finish one course before touching anything else. It's an hour, not a weekend.
  2. Browse the official Skills library: Look through the example skills and find one or two close to your actual work. Install them in Claude Code, or upload one in Claude.ai if you're on a paid plan with code execution on.
  3. Add two or three subagents, not fifty: If you use Claude Code, pick the two or three subagents closest to your actual stack from the community repo. Read what each one does before installing it. Expand later, once you're actually using the first few.

Tip: Do this in order. Skipping straight to subagents without the Academy fundamentals or a couple of relevant Skills is the fastest way to end up with a cluttered setup you don't actually understand or use.

What week one actually looks like

Finish one Claude Academy course~1 hour
Install one Skill relevant to your actual work~10 min
Add two subagents and try each on a real task~15 min

Under two hours, spread across a week if that's easier. The point isn't speed, it's that none of this requires a weekend you don't have or a plan you haven't already got.
