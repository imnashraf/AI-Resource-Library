Chapter 01: What Claude Actually Is

Most people treat Claude like a search engine. You type a question, it gives you an answer, you close the tab. That's probably 5% of what it can do. The rest comes from understanding how to set it up properly.

Claude is made by Anthropic. It's a large language model, but that description undersells it. With the right setup, Claude becomes a work tool that handles real tasks: writing documents, analysing data, managing email, building software, creating presentations, and running automations.

The difference between someone who uses Claude casually and someone who uses it properly is entirely about setup. The same model, the same AI, producing completely different quality output. This guide covers that setup.

What You Get Access To

Claude.ai: The web and mobile chat interface. This is where most people start.

Claude Projects: Persistent workspaces with custom instructions and uploaded files.

Memory: Claude remembers your preferences across conversations automatically.

Skills: Packaged instructions that teach Claude how to handle specific workflows.

MCP Connectors: Plug Claude into Gmail, Google Calendar, Notion, Figma, and more.

Claude Code: A command line tool for developers. Agentic coding from your terminal.

Free vs Pro: What You Actually Need

The free plan gives you access to Claude's base model with limited messages. The Pro plan ($20/month) unlocks Projects, more messages, the latest models, and priority access. For this guide, I'll tell you when something needs Pro.

My honest take: if you're going to use Claude for actual work, the Pro plan pays for itself in the first week. But start free, run through this guide, and upgrade when you hit the limit. You'll know when.

Chapter 02: Claude Projects

This is the single most important feature most people never set up. A Claude Project gives you a persistent workspace where Claude always has the context it needs. No more re-explaining who you are, what you do, or how you want things done.

Without a Project, every new conversation starts from zero. Claude has no idea who you are, what your business does, or what tone you want. With a Project, all of that is loaded automatically. The output quality difference is night and day.

Step 1

Create Your First Project

Go to claude.ai and click 'Projects' in the sidebar. Click 'Create Project' and give it a clear name. Example: 'Content Writing' or 'Business Operations'.

Tip: Start with one Project for your most common use case. You can create more later.

Step 2

Write Your Project Instructions

This is the system prompt that loads every time you open a conversation inside this Project. It tells Claude who you are, what you do, and how to behave.

Tip: Think of this as the brief you'd give a new employee on day one.

Step 3

Upload Your Knowledge Files

Drag and drop up to 200 files per Project. Claude reads them automatically when relevant. Brand guides, SOPs, product docs, strategy docs, templates, style guides.

Tip: PDFs, docs, text files, code files, spreadsheets. Claude reads them all.

Example Project Instructions: paste this in:

You are helping Max Johnson with content writing. Max runs an AI agency called Briix based in Manchester. Tone: British confidence, direct, no hype language. Always use short sentences. Maximum 15 words each. Never use em dashes or hyphens in scripts. When writing TikTok scripts, use the talking head format: Hook > Agitation > Content > Proof > CTA. CTA format: Comment [WORD] and I'll send you [thing].

Replace this with your own details. The more specific you are about who you are, what you do, and how you want Claude to behave, the better every single output will be.

Chapter 03: The Memory System

Claude has a memory system that learns about you over time. It picks up your preferences, your work context, your writing style, and applies that knowledge across every conversation. Most people don't even know it exists.

Memory works in the background. As you chat with Claude, it notices patterns and stores them. Your name, your role, tools you use, formatting preferences, things you've told it about your work. Next time you start a new conversation, that context is already there.

Step 1

Check Your Memory Settings

Go to Settings > Memory in claude.ai. Make sure 'Learn from conversations' is enabled. You can view what Claude has learned about you here.

Step 2

Actively Teach Claude About You

Don't wait for Claude to figure you out passively. Tell it directly: 'Remember that I run a design agency' or 'Remember I prefer British English spelling'.

Tip: Say 'remember this' and Claude will store it explicitly. You can also say 'forget this'.

Step 3

Set Your User Preferences

Go to Settings > User Preferences in claude.ai. Write a short paragraph about how you want Claude to behave. Your tone, formatting preferences, expertise level.

Example User Preferences:

I'm a business owner, not a developer. Keep technical explanations simple. I prefer British English. Use short, direct sentences. Don't give me long preambles before answering. When I ask for a document, just create it. No bullet points unless I ask for them.

Chapter 04: Custom Instructions That Change Everything

The difference between mediocre Claude output and genuinely useful output almost always comes down to how well you've briefed it. Custom instructions are the highest-leverage thing you can write.

The Anatomy of Great Instructions

Who you are: Your name, role, company, what you do. Claude needs to know who it's helping.

What you need: The specific types of output you'll ask for. Scripts, emails, reports, code.

How you want it: Tone, length, formatting rules. Be specific: 'short sentences, max 15 words'.

What to avoid: Banned phrases, formatting you hate, approaches that don't work for you.

Examples: Paste in real examples of output you like. This is the single most effective technique.

Three Rules That Make Instructions Work

1: Be specific, not general. 'Write in a casual tone' is weak. 'Write like you're telling a mate about something you found, short sentences, British English, no hype' is strong.

2: Include examples. Paste in a paragraph of writing you like and say 'match this tone and style'. Claude will mirror it almost exactly.

3: Tell Claude what not to do. Banning specific phrases and patterns is often more effective than describing what you want. 'Never use em dashes, never start with In today's, never use bullet points unless asked' removes the most common AI tells.

Chapter 05: Skills

A skill is a set of instructions packaged as a folder that teaches Claude how to handle a specific task or workflow. Instead of re-explaining your process every time, skills let you teach Claude once and benefit every time.

Think of it like this: Claude is already good at general tasks. Skills make it excellent at specific ones. A frontend design skill gives Claude an actual design system to work from. A document creation skill makes it produce properly formatted Word docs, not just markdown. A marketing skill gives it your exact frameworks.

How Skills Work

Step 1

Find or Create a Skill

Skills are folders containing a SKILL.md file with instructions. You can download community skills from GitHub or create your own. Anthropic has published a directory of official skills.

Tip: GitHub search 'claude skills' to find community-built skills for almost anything.

Step 2

Upload the Skill to Claude

Go to Settings > Capabilities > Skills in claude.ai. Click 'Upload skill' and select the skill folder (zipped). Toggle it on and Claude will load it automatically.

Step 3

Use the Skill

You don't need to do anything special. Just start a chat. Claude reads the skill description and activates it when relevant. Ask for a document and the docx skill fires.

Five Skills Worth Installing Right Now

Frontend Design: Gives Claude a proper design system for building web interfaces. The output quality change is immediate.

Document Creation (docx): Creates properly formatted Word documents with headers, tables, page numbers. Not just markdown.

PDF Creation: Generate, fill, merge, and split PDF files directly inside Claude.

Spreadsheet (xlsx): Build and edit Excel files with formulas, charts, and formatting.

Presentation (pptx): Create slide decks with proper layouts, not just bullet points on white backgrounds.

Chapter 06: MCP Connectors

MCP stands for Model Context Protocol. In practical terms, it's how you plug Claude into your existing tools. Gmail, Google Calendar, Notion, Figma, Slack, databases, and more. Once connected, Claude can read your data and take actions inside those tools.

This is where Claude stops being a chatbot and starts being a work tool. Instead of copying information between apps, Claude sits in the middle and handles the coordination. Read your emails, check your calendar, draft a response, schedule a meeting. All from one conversation.

How to Connect an MCP Server

Step 1

Find the Connector

In claude.ai, go to Settings > Connected Apps. You'll see available integrations listed. Click the one you want, for example Gmail or Google Calendar.

Step 2

Authorise the Connection

Claude will ask you to sign in to your account for that service and grant permissions. Standard OAuth flow. Same as connecting any other app.

Tip: You can revoke access at any time from Settings.

Step 3

Use It Naturally

Once connected, just ask Claude to do things. 'Check my calendar for tomorrow' or 'Draft a reply to that email from Sarah'. Claude handles the rest.

Connectors Available Right Now

  • Gmail: Read, search, draft, and send emails
  • Google Calendar: View, create, and manage events
  • Google Drive: Search and access your files
  • Notion: Read and write to your Notion workspace
  • Figma: Access your design files and create diagrams
  • Slack: Read messages and post updates
  • Linear: Manage projects, issues, and sprints
  • GitHub: Access repos, issues, and pull requests

Note: New connectors are being added regularly. Check Settings > Connected Apps for the latest. Community-built MCP servers are also available on GitHub for hundreds of other services.

Chapter 07: Claude Code

Claude Code is a command line tool that lets developers work with Claude directly from the terminal. If you write code, this changes how you work. If you don't write code, skip to Chapter 08.

Instead of copying code back and forth between Claude and your editor, Claude Code runs in your project directory. It can read your codebase, understand the full context, write code, run tests, fix bugs, and commit changes. It's agentic, meaning you give it a task and it figures out the steps.

Step 1

Install Claude Code

You need Node.js 18 or higher installed first. Then run the install command in your terminal:

npm install -g @anthropic-ai/claude-code

Step 2

Authenticate

Run 'claude' in your terminal. It will ask you to authenticate with your Anthropic account. Follow the prompts. Takes about 30 seconds.

Step 3

Use It in a Project

Navigate to your project folder and run 'claude'. It reads your codebase automatically. Ask it to build features, fix bugs, refactor code, write tests.

The CLAUDE.md File

Add a CLAUDE.md file to your project root. Claude Code reads it automatically at the start of every session. Use it for project-specific instructions: coding standards, architecture decisions, file structure notes, testing requirements. This is the equivalent of Project instructions for the command line.

Example CLAUDE.md:

# Project: My SaaS App Stack: Next.js 14, TypeScript, Tailwind, Supabase Always use server components unless client needed. Run 'npm test' after any code changes. Follow the existing file naming convention. Never modify files in /lib/core without asking.

Day 1: Account and Memory

  • Sign up at claude.ai (or sign in if you already have an account)
  • Enable Memory in Settings > Memory
  • Write your User Preferences (see Chapter 03 for the template)
  • Have three normal conversations so Claude starts learning about you

Day 2: Your First Project

  • Create a Project for your most common work task
  • Write custom instructions (use the template from Chapter 02)
  • Upload 3 to 5 relevant files (brand guide, SOP, examples)
  • Run a real task inside the Project and compare the output quality

Day 3: Connect Your Tools

  • Go to Settings > Connected Apps
  • Connect Gmail and Google Calendar as a starting point
  • Ask Claude to check your calendar for the week
  • Ask Claude to summarise your unread emails

Day 4: Skills

  • Download one skill that matches your work (see Chapter 05)
  • Upload it via Settings > Capabilities > Skills
  • Test it with a real task: create a document, build a page
  • Compare the output with and without the skill active

Day 5: Build Your System

  • Create 2 to 3 more Projects for different areas of your work
  • Upload relevant files to each one
  • Connect any other tools you use daily
  • You now have a Claude setup that actually works for you
