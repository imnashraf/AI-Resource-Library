Claude Humanizer Setup Guide

Max Johnson@maxjohnscn

Claude Humanizer Setup Guide, Make your AI writing sound human.

The Claude Humanizer is a free, open-source skill for Claude Code that rewrites AI-generated text to sound natural and human. It's based on Wikipedia's guide to spotting AI writing, and it fixes all the classic AI tells: the em dashes, the buzzwords, the robotic sentence structures, the overly formal phrasing.

In short: paste in your AI-written content, and get back something that actually sounds like a person wrote it.

✓Em dash overuse
✓Buzzwords
✓Filler openers
✓Rule of three
✓Vague attributions
✓Over-hyphenation
✓Promotional language
✓Robotic sentence structure

What you need:

  • A computer running Mac, Windows, or Linux
  • Claude Code installed, the free command-line tool from Anthropic
  • A terminal / command prompt
  • Git installed, a free tool for downloading code from the internet

Step 1, Install Claude Code

Claude Code is the tool that runs the Humanizer skill. If you already have it, skip to Step 2.

# Install Claude Code npm install -g @anthropic-ai/claude-code # Log in claude login

Follow the instructions, it will open a browser window for you to authorise.

TIP: If you see 'command not found' when typing npm, you need to install Node.js first. Visit nodejs.org and download the LTS version.

Step 2, Install Git (if needed)

Git is what we use to download the Humanizer from GitHub. Most Macs already have it. To check, open your terminal and type:

git --version

If you see a version number, you're good, skip to Step 3. If you get an error, download and install Git from: https://git-scm.com/downloads

Step 3, Install the Humanizer Skill

The GitHub repository: github.com/blader/humanizer

Run the install commands. Open your terminal and run these two commands, one at a time:

# First, create the skills folder: mkdir -p ~/.claude/skills # Then, download the Humanizer into it: git clone https://github.com/blader/humanizer.git ~/.claude/skills/humanizer

Done! You should see a message saying 'Cloning into...' followed by some download progress. That means it worked.

Already downloaded the file manually? If you already have the SKILL.md file saved somewhere, you can copy it manually instead:

mkdir -p ~/.claude/skills/humanizer cp SKILL.md ~/.claude/skills/humanizer/

Step 4, Use the Humanizer

  1. Open your terminal
  2. Navigate to the folder containing the text you want to humanize (or just stay in your home folder)
  3. Start Claude Code by typing: claude
  4. Once Claude Code is running, paste your AI-generated text and ask it to humanize it:
Humanize this text: [paste your text here]

Claude Code will detect the Humanizer skill automatically and rewrite your content to remove AI patterns.

BEST RESULTS: The skill works best on content that's already mostly written, blog posts, emails, captions, LinkedIn posts, etc. It's designed to strip out robotic phrasing, not write from scratch.

What the Humanizer Fixes

The skill is based on Wikipedia's guide to AI writing patterns. Here are some of the things it removes:

  • Em dash overuse, the constant 'em dashes' AI loves
  • Buzzwords, 'testament', 'delve', 'nuanced', 'pivotal', 'transformative'
  • Filler openers, 'Great question!', 'Certainly!', 'Of course!'
  • Rule of three, AI always lists things in threes
  • Vague attributions, 'Industry observers have noted...'
  • Over-hyphenation, 'cross-functional', 'data-driven', 'client-facing'
  • Promotional language, making everything sound like a press release

It also runs a final 'obviously AI-generated' audit pass and rewrites anything that still sounds off.

Troubleshooting

'command not found: git', Git isn't installed. Go to git-scm.com/downloads and install it, then try again.

'command not found: claude', Claude Code isn't installed or the install didn't complete. Re-run: npm install -g @anthropic-ai/claude-code

The skill doesn't seem to activate, Make sure the file is in exactly the right place. Run this to check: ls ~/.claude/skills/humanizer/. You should see SKILL.md listed. If the folder is empty or doesn't exist, re-run the git clone command from Step 3.

Something else isn't working, Check the GitHub repo for the latest instructions and known issues: https://github.com/blader/humanizer
