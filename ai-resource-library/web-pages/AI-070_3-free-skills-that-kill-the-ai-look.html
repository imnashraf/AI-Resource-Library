Note

All three tools in this guide are Claude Code skills. They install through a terminal and run inside Claude Code (or Claude Desktop's Code tab, or Cowork), not through the Skills uploader inside the claude.ai web chat. You'll need Claude Code installed and a project open in a terminal before you start. Each install takes a couple of minutes.

Why these three

Each one fixes a different part of the same problem. Emil Kowalski's skill fixes motion. Impeccable fixes structure and gives you a repeatable design system. Taste fixes the reasoning behind the choices Claude makes when nobody's told it what to do. Run all three together and each covers a gap the others don't.

Chapter 01: Why Every AI Site Looks The Same

You can spot an AI-built website in about two seconds. Generic gradient, Inter font, zero motion. It happens because every model defaults to the same safe patterns, so almost every vibe-coded site ends up looking basically the same.

None of the three tools in this guide generate a design from nothing. They sit on top of Claude Code and steer it away from its defaults, toward proper motion, a real design system, and design decisions it can actually explain instead of copying blindly.

The three tells

  • Generic gradient: Purple-to-blue, every time, whether or not it fits the brand.
  • Inter, everywhere: Headings, body, buttons, all the same safe system font.
  • Zero motion: Nothing moves, or it's slapped on with no thought to easing.
Why this happens

Every model was trained on the same handful of SaaS templates. Left to its own defaults, an AI coding agent reaches for the same shortcuts every time. These three skills each override a different part of that default: motion, structure, and the reasoning behind design choices.

What each skill fixes

Motion

Emil Kowalski's skill: correct easing, timing, and restraint

Structure

Impeccable: a shared design system and a slop detector

Judgement

Taste: the reasoning behind a design choice, not just the value

Chapter 02 · Skill One: Emil Kowalski's Motion Skill

Emil Kowalski is a design engineer at Linear, previously at Vercel, and the creator of Sonner and Vaul, two widely used React components. He also runs animations.dev, a course on UI animation. This skill encodes his approach to motion into Claude Code.

When you vibe-code a UI, it tends to come out static, or with motion bolted on with the wrong easing curve. This skill teaches Claude to use proper easing and timing instead, so animation feels intentional rather than decorative.

Built by: Emil Kowalski (Linear, ex-Vercel)

Repo: github.com/emilkowalski/skills

Main skill: emil-design-eng

Triggers on: Reviewing UI code, building a component, adding animation

Note

This command installs a small bundle, not just one file: the main design/animation skill plus a few companions (an animation reviewer, an animation vocabulary lookup, and an Expo/React Native variant). That's expected, they all live under the same repo. You don't need to install them separately.

When it kicks in

You don't call this skill by name. Just ask Claude normally:

  • "Build me a modal that fades in when it opens"
  • "Review the animations in this component"
  • "This hover effect feels off, fix it"

Install command

npx skills@latest add emilkowalski/skills

Chapter 03 · Skill Two: Impeccable

Impeccable was built by Paul Bakaus and started as an extension of Anthropic's own frontend-design skill. It adds a shared design vocabulary between you and Claude, 23 commands covering typography, colour, spacing, and layout, plus dozens of deterministic checks that catch the obvious AI tells automatically.

The command most worth knowing is /impeccable polish. Run it right before you push, and it does a final pass across the UI: alignment, spacing, and detail cleanup, checked against the design system it already knows.

Built by: Paul Bakaus

Repo: github.com/pbakaus/impeccable

Commands: 23, all run through /impeccable

First run: /impeccable init · then /impeccable polish before shipping

Note

The command is /impeccable polish, not a bare /polish. If you use it often, run /impeccable pin polish once and it creates a standalone /polish shortcut for that project.

A few more commands worth knowing

  • /impeccable audit: accessibility, performance, responsive checks
  • /impeccable critique: a UX review of hierarchy and clarity
  • /impeccable distill: strips a UI back to its essence

Install command

npx impeccable install

Chapter 04 · Skill Three: Taste

Taste Skill is one of the fastest-growing repos in this space. Instead of just handing Claude a colour code, it teaches the reasoning behind the choice: why this spacing value, why this palette, why this layout, so Claude can make the right call on a page it's never seen before, not just copy a pattern.

70k+ stars · MIT licensed · Works with Claude Code, Cursor, Codex

Built by: Leonxlnx

Repo: github.com/leonxlnx/taste-skill

Default skill: design-taste-frontend

Dials: Layout variance, motion intensity, visual density

Correction

At close to 60,000 stars this was already one of the biggest repos of its kind. It has since passed 70,000 and is still climbing, so treat any star count, including this one, as a floor rather than a fixed number by the time you read this.

A single skill, multiple variants

The repo bundles more than one flavour under the same install. The default, design-taste-frontend, covers most projects. There's also a stricter GPT/Codex variant, a redesign-focused variant for existing codebases, and a few fixed visual directions (minimalist, brutalist, high-end) you can install by name instead.

Install command

npx skills add https://github.com/Leonxlnx/taste-skill

Chapter 05: Install All Three

All three take minutes to set up. Run the commands, restart, then just talk to Claude as normal.

1
Open a terminal in your project

Claude Code needs to run from your project folder, not a random directory.

2
Run the three install commands

One at a time, in any order. Each one adds its skill files under .claude/skills/ for that project.

3
Restart or reload Claude Code

Skills are picked up on the next session, not mid-conversation.

4
Run /impeccable init once

This is the only one of the three that needs a manual first run. Emil's skill and Taste trigger automatically when you ask for UI work.

5
Build something, then run /impeccable polish

Compare the before and after. That's the whole point of this setup.

Tip: All three run inside the same project without conflicting. If you only have time for one today, install Impeccable first, it's the only one with a manual init step, and it gives you the most immediate before/after comparison.

Run all three

npx skills@latest add emilkowalski/skills
npx impeccable install
npx skills add https://github.com/Leonxlnx/taste-skill
