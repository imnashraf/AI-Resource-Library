Chapter 01: What Claude Routines Actually Are

"Claude Routines" isn't an official product name. The feature behind it is scheduled tasks in Claude Cowork: you describe a job once in plain English, Claude saves it as a set of instructions, and it runs automatically on the cadence you pick, whether or not your computer is switched on.

Each run starts a fresh Cowork session with access to whatever connectors, skills and plugins you've already set up, so a routine can genuinely search Slack, read a spreadsheet, browse the web, or draft an email, not just generate text.

Cadence Options

Hourly, daily, weekly, weekdays, or manual (run it yourself on demand). You set the time when you create the task.

Who Can Use It

Any paid Claude plan: Pro, Max, Team or Enterprise. Free plans don't get scheduled tasks or connectors.

Two approval modes

Automatically approve lets Claude work through a routine without pausing you for every step, but it still screens each action for safety before running it. Skip all approvals removes that screening entirely. For anything unattended, start with Automatically approve.

Honest limit

A routine only reaches the tools you've connected. If a routine below needs Slack, Gmail or a specific ad platform and you haven't connected it, Claude will tell you it can't do that part rather than making something up, so connect first.

Chapter 02: How To Set One Up

Every routine in this guide is built the same way. Four steps, about two minutes each the first time.

1. Open Cowork and click Scheduled

In the left sidebar of Claude Cowork, click "Scheduled" to land on the Scheduled tasks page.

2. Choose how you want to build it

"Create with Claude" lets you describe the task in plain English and Claude asks clarifying questions before creating it. "Set up manually" gives you direct fields: name, prompt, approval mode, cadence, model, and which folder to work in.

3. Connect whatever the routine needs first

Gmail, Slack, Drive, or any third-party connector. Do this before you schedule the task, not after, so the first run isn't wasted finding out something isn't connected.

4. Confirm and let it run

Claude will state the task name, schedule and what it does before asking you to confirm. From the Scheduled page you can review upcoming and past runs, pause, edit, delete, or run any task on demand at any time.

Tip

Run a new routine manually once before you schedule its first automatic run. It's the fastest way to catch a missing connector or a vague prompt before it runs unattended.

Routine 01: Daily Content Generator

Daily · 9:00am

Researches trending topics in your niche, then writes a full script in your voice, ready to film that day.

Prompt to paste in "Create with Claude":

Every day at 9am, research the top trending topics in [your niche] on Reddit, Instagram
and X. Pick the one most likely to perform well as a short-form video. Write a full script in
my voice: [describe your tone and style, or paste 2-3 past scripts as reference]. Format it
ready to read on camera.
Note

Claude doesn't have a native connector into Reddit, Instagram or X. It reaches them through web search and browsing, so it sees public, indexable content. Anything behind a login wall, which is most of Instagram and some of X, won't be visible. For deeper social listening, pair this with a dedicated scraping connector.

Routine 02: Daily Ad Report

Daily · 7:00am

Pulls yesterday's ad spend and performance, and tells you exactly how the business performed.

Prompt to paste in "Create with Claude":

Every day at 7am, pull yesterday's ad performance across [your ad platforms] and pipeline
data from [your CRM or spreadsheet]. Summarise total spend, ROAS, and pipeline movement in
three sentences, then break it down by platform in a table.
Warning

Anthropic doesn't build a native Meta Ads or Google Ads connector. You'll need a third-party connector authenticated to your ad accounts (search Claude's connector directory for one), or export the numbers into a Google Sheet each day and have this routine read that instead. Either way, the connector has to exist before the prompt can do anything with it.

Routine 03: Weekly Competitor Analysis

Weekly · Monday morning

Reviews accounts making content in your niche and hands you a shortlist of what's working, ready to adapt.

Prompt to paste in "Create with Claude":

Every Monday, look at these [30] competitor accounts: [list handles or links]. Identify
which posts from the last 7 days performed best. Summarise the hook, format and topic of the
top 5, and suggest how I'd adapt each one for my own channel.
Warning

Claude can't log into Instagram or TikTok to pull private engagement numbers, and downloading someone else's video to reuse the footage is a copyright and platform terms-of-service problem, not just a technical one. Keep this routine to analysis: hooks, structure and topics to adapt, not literal downloads. If you genuinely need saved reference clips, that requires a licensed scraping tool, used within the platform's terms.

Routine 04: Daily n8n Error Report

Triggered · On failure

The moment an n8n workflow breaks, tells you exactly what happened and how to fix it.

Prompt to paste in "Create with Claude":

When you receive an n8n workflow error, read the error payload: workflow name, node that
failed, and the error message. Explain in plain language what broke and why, then give me the
specific fix, whether that's a credential, a field mapping, or a node configuration change.
Note

This one doesn't fit Cowork's clock-based scheduling, because it needs to fire on an event, not a time of day. The closest real match is Claude Code's Routines feature (currently in research preview), which supports API triggers: n8n's Error Trigger node calls a webhook, which hits your routine's dedicated endpoint, which starts a Claude session with the error already in it. This is a step more technical than the other four routines here and needs an API key.

Routine 05: Daily Email Handler

Daily

Reads your inbox, categorises everything, and drafts replies to the routine stuff so you're not starting from a blank screen.

Prompt to paste in "Create with Claude":

Every morning, go through my inbox. Categorise everything as: needs a reply, FYI, or
ignore. Draft replies for anything routine, in my voice. Leave anything involving money,
contracts, or an unhappy client as a flagged draft with a one-line note on why it needs my
eyes first.
Warning

This one is more limited than the video suggests, worth knowing before you build it. Claude's Gmail connector reads and drafts, but it cannot send. Every reply, routine or not, lands as an unsent draft waiting in Gmail. There's no version of this where the low-stakes emails send themselves and only the tricky ones need you. Budget five minutes each morning to skim and send the drafts yourself. The Outlook/Microsoft 365 connector can send, but only if a Team or Enterprise admin has switched on write tools, and it's off by default.

Chapter 05: Setup Checklist & Common Mistakes

  • Connect the tool before you schedule the task, not after. A routine can only reach what's already connected.
  • Start with "Automatically approve," not "Skip all approvals." The first still screens each action for safety. The second doesn't check anything.
  • Run it manually once before you schedule it. Read the actual output before you let it run unattended.
  • Don't schedule anything you can't afford to have go wrong unsupervised, especially anything that sends money or messages.
  • Check the Scheduled page weekly. Pause anything that's stopped being useful instead of letting it run for the sake of it.
  • Keep each routine to one job. A routine trying to do five things at once is where the errors creep in.
