Marketing Skills Complete Setup Guide for Claude Code

Max Johnson@maxjohnscn

This guide gets you from zero to a fully loaded marketing team inside Claude Code. No technical experience needed. Follow the steps in order, the whole thing takes about 10 minutes.

What you'll have when this is set up:

  • A full suite of marketing skills loaded into Claude Code
  • Cold email sequences written and ready to send
  • Landing pages and ad creative generated on demand
  • Content strategy, SEO, competitor analysis, all available in plain English

The Skills, What You're Getting. This is a free GitHub repo built by Corey Haines, a collection of marketing skill files Claude Code reads automatically. Every folder is a different marketing capability.

Step 01, Download the GitHub Repo, Free

Go to github.com/coreyhaines31/marketingskills in your browser. Click the green Code button, then Download ZIP. It will download to your Downloads folder as a zip file. Double click to unpack it.

TIP: You only need the skills folder from inside the repo. The .github and .claude-plugin folders are GitHub admin files, ignore those.

Step 02, Create Your Project Folder, 5 minutes

Create a new folder on your Desktop or Documents, name it something like briix-marketing. Open the skills folder from the repo you just downloaded and copy everything inside it into your new folder. Then create a subfolder called brand-assets.

Your folder structure should look like this:

briix-marketing/ ad-creative/ cold-email/ copywriting/ content-strategy/ email-sequence/ ai-seo/ ... (all other skill folders) brand-assets/ briix-logo.png brand-guidelines.pdf

TIP: Put anything that defines your brand into the brand-assets folder, logo, brand guidelines, tone of voice doc, examples of existing content. The more Claude has to reference, the more on-brand the output.

Step 03, Open Claude Code in Your Folder, Terminal

Open your Terminal app (Mac) or Command Prompt (Windows). Navigate into your project folder using the command below, then launch Claude Code.

# Navigate to your project folder cd Desktop/briix-marketing # Launch Claude Code claude

TIP: If your folder is saved somewhere other than Desktop, adjust the path. For example: cd Documents/briix-marketing

Step 04, Verify the Skills Are Loaded, Test

Once Claude Code is open, paste the prompt below. Claude should list back every marketing skill it has access to. If it does, everything is working.

What marketing skills do you have available in this project?

WARNING: If Claude lists back the skills, ad-creative, cold-email, copywriting etc, you are fully set up. If it doesn't recognise any skills, make sure you launched Claude Code from inside the briix-marketing folder, not from your Desktop or home directory.

Step 05, Run Your First Real Task, Test with your brand

Now test it with something real. Paste the prompt below and watch what it produces. It should reference your brand assets and produce something specific, not something generic.

Test prompt, paste into Claude Code:

Using my brand assets, write me a 3-part cold email sequence targeting small business owners in the UK who haven't considered AI automation yet. Each email should be under 150 words, conversational, and end with a clear next step.

TIP: Good output looks specific to your brand, it references the business, uses the right tone, and doesn't sound like a generic template. If it sounds generic, make sure your brand-assets folder has enough context.

What Else It Can Do

Once you're set up, here are some of the other things you can ask it to do:

  • Write and schedule full email nurture sequences for new leads
  • Generate ad creative variations for Facebook and LinkedIn campaigns
  • Build a full content strategy for the next 90 days across platforms
  • Run competitor analysis and build positioning against specific alternatives
  • Create A/B test frameworks for any landing page or email
  • Write SEO-optimised blog posts and landing page copy
  • Build out a full product launch sequence

TIP: The more specific your prompt, the better the output. Always reference your brand assets folder in the prompt and give Claude as much context as possible about who you're targeting.
