Ruflo Multi-Agent Framework Setup Guide

What you'll have when done:

  • 60+ specialist agents running simultaneously inside Claude Code
  • Automatic task routing, simple jobs skip the model, complex ones use Opus
  • Self-learning memory that improves routing accuracy after every run

Setup Steps

Step 1, Navigate to your project directory. Open your terminal and cd into the project where you want Ruflo running. If you don't have a project yet, create a new folder and navigate into it.

cd your-project-folder

Step 2, Run the Ruflo initialisation wizard. This single command installs Ruflo and runs the interactive setup wizard. It will configure your project, set up the agent system, and generate your CLAUDE.md and settings files automatically.

npx ruflo@latest init --wizard

TIP: If you prefer Bun for faster installs, use: bunx ruflo@latest init --wizard

Step 3, Add Ruflo as an MCP server in Claude Code. This connects all 313 Ruflo MCP tools directly into Claude Code so Claude can use them without any additional prompting.

claude mcp add ruflo -- npx -y ruflo@latest mcp start # Verify it connected: claude mcp list

Step 4, Run the health check. This checks your installation, fixes any common issues automatically, and confirms everything is working correctly.

npx ruflo doctor --fix

TIP: If the doctor flags any issues it can't auto-fix, re-run the wizard: npx ruflo@latest init --wizard

Step 5, Start the background learning daemon. This activates the self-learning system that stores successful patterns and improves agent routing over time. Run this once, it persists in the background.

npx ruflo daemon start

Step 6, Start using it. Open Claude Code normally. Ruflo hooks into the workflow automatically. You don't need to do anything different, just work as normal and the multi-agent system handles coordination in the background.

NOTE: You don't need to learn the 313 MCP tools or the CLI commands to get value from Ruflo. After init, just use Claude Code as normal. The hooks system routes tasks to the right agents automatically.

Optional, Spawn a Manual Swarm

If you want to manually spin up a coordinated swarm for a specific build, use the commands below. This gives you full control over which agents run and how they coordinate.

# Initialise a hierarchical swarm npx ruflo swarm init --topology hierarchical --max-agents 8 --strategy specialized # Spawn specialist agents npx ruflo agent spawn -t coder --name my-coder npx ruflo agent spawn -t tester --name my-tester npx ruflo agent spawn -t reviewer --name my-reviewer npx ruflo agent spawn -t security --name my-security

TIP: For most projects the automatic routing handles this for you. Manual swarms are useful when you want to dedicate specific agents to a long-running parallel build.

How the Cost Reduction Works

Ruflo uses intelligent 3-tier model routing to reduce API costs by up to 75%. Every task is analysed before it hits a model.
