Before You Start

A few things get reused across all eight, so here's how to set them up once.

01 Projects

This is a dedicated workspace inside Claude. It remembers custom instructions and any files you upload, so you're not re-explaining yourself every time. Click "Projects" in the sidebar, then "New project." Give it a name, add your instructions, upload files if the system needs them.

02 Web Search

Built in, no setup. Just make sure it's toggled on.

03 File Uploads

Click the plus icon in the chat box. Claude reads PDFs, docs, spreadsheets and CSVs directly, no converting anything first.

04 Google Drive Connector

Optional, but worth turning on if your templates and reference docs already live in Drive. Click the plus icon and toggle it on. Saves you re-uploading the same file every time.

System 01 of 08: Proposal Generator

You give it the call notes and it writes the whole proposal, pricing, scope and all, ready to send in the next ten minutes.

Build time: About 20 minutes

Worth knowing

The output is only as sharp as the notes going in. Rough bullet points work fine, you don't need full sentences.

Setup

  1. Create a Project called "Proposals."
  2. Upload your proposal template and your rate card.
  3. In the Project instructions, set the format: "When I give you call notes, write a full proposal using my template and rate card. Match the scope to what was actually discussed, don't pad it out."
  4. After each call, drop in your notes and ask for the proposal.

System 02 of 08: Competitor Watch

It checks your top competitors every morning, their posts, their pricing, their new launches, and hands you the one thing that actually matters.

Build time: About 15 minutes

Worth knowing

This isn't a live alert system, you still have to open the chat and ask. It's replacing the manual scroll through their pages, not automating it away entirely.

Setup

  1. Create a Project called "Competitor Watch."
  2. Turn on web search.
  3. List who to track in the Project instructions: "Track [competitor names]. When I ask for an update, search for anything new from them in the last week, pricing changes, new posts, launches, and give me the single most important thing, not a list."
  4. Run it whenever you want a check, it doesn't run on its own in the background.

System 03 of 08: Sales Call Debrief

Drop in the call notes or transcript and it pulls out what the prospect actually cares about, the objections, and the exact next step to take.

Build time: About 15 minutes

Worth knowing

If your call tool doesn't auto-transcribe, your own rough notes work almost as well, the debrief quality comes from what's in the notes, not the polish of the transcript.

Setup

  1. Create a Project called "Call Debrief."
  2. Most call tools, Zoom, Fathom, Fireflies, already spit out a text transcript after the call. That's what you're pasting in, Claude doesn't transcribe audio itself.
  3. Save the debrief format: "When I paste a call transcript, give me: what they actually care about, the objections they raised, and the one next step to take."
  4. Paste the transcript in straight after the call, while it's still fresh.

System 04 of 08: SOP Builder

You talk through how you do something once and it turns that into a proper written process, ready to hand to anyone on the team.

Build time: About 20 minutes

Worth knowing

Talk through it exactly as you'd explain it to a new hire standing next to you, including the bits that feel obvious. Those are usually the bits that get missed.

Setup

  1. Create a Project called "SOP Builder."
  2. Upload one example of a process doc you like the format of, if you've got one. If not, skip this.
  3. Set the instructions: "When I talk through a process, turn it into a numbered SOP. Number every step, flag anything that needs a screenshot, keep the language plain enough that someone new could follow it."
  4. Talk through the process in a message, typed or dictated with your phone's voice-to-text, then ask for the SOP.

System 05 of 08: Contract Reviewer

Every contract goes through it before you sign anything, the risky clauses, the missing bits, the stuff your lawyer would flag.

Build time: About 20 minutes

Worth knowing

This catches what's different from your normal terms, it's not a substitute for an actual lawyer on anything high stakes. Treat it as the first pass, not the last one.

Setup

  1. Create a Project called "Contract Review."
  2. Upload your standard terms or a contract you're happy with as the reference point.
  3. Set the instructions: "When I upload a contract, compare it against my standard terms. Flag anything unusually risky, anything missing that's normally in mine, and summarise it in plain English."
  4. Upload any new contract before signing and ask for the review.

System 06 of 08: Hiring Filter

Every application lands in one place and it ranks them against what you're actually looking for, not just keywords on a page.

Build time: About 20 minutes

Worth knowing

Be specific in the role brief about what actually matters versus what's nice to have. A vague brief gets you a vague ranking.

Setup

  1. Create a Project called "Hiring."
  2. Upload your role brief and a scoring template, what actually matters for this role, weighted.
  3. Set the instructions: "When I upload a CV or application, score it against my role brief and template. Give me a score and the one line reason why."
  4. Upload applications as they come in, or in a batch at the end of the week.

System 07 of 08: Website Copy Auditor

Point it at your site and it tells you exactly where people are dropping off, in plain language, not sat in an analytics dashboard.

Build time: About 20 minutes

Worth knowing

It's reading the page and reasoning about the copy, it isn't pulling live analytics data itself. The more specific your analytics summary, the sharper the read.

Setup

  1. Create a Project called "Copy Audit."
  2. Turn on web search so it can actually pull your live pages.
  3. Upload a summary of your analytics, whatever you're already tracking in, drop off points, bounce rate, whatever you've got.
  4. Ask: "Look at [your site URL] and my analytics summary. Tell me where the copy is likely losing people and what to change first."

System 08 of 08: Personal Learning Coach

Tell it what you're trying to learn and it builds you a real path, then quizzes you on it until it actually sticks.

Build time: About 15 minutes

Worth knowing

It only tracks progress within that one Project, so don't start a fresh chat each time, you'll lose the thread of where you were.

Setup

  1. Create a Project called "Learning Coach."
  2. Set the instructions: "When I tell you what I'm trying to learn, build me a structured path with milestones. Quiz me on what I've covered when I ask, and don't move me forward until I actually get it."
  3. Tell it what you're learning and your rough timeframe.
  4. Come back to the same Project each session so it remembers where you're up to.

Eight systems. One weekend.

Pick the one that's already costing you the most time each week. Build it first. The rest can wait.
