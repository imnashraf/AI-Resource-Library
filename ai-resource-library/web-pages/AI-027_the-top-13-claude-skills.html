Skill 01, marketingskills

★ 17.1k GitHub stars, A full marketing toolkit in one install

Built by Corey Haines, this repo drops 20+ marketing skills into Claude Code in one command. Covers SEO audits, copywriting, email sequences, CRO, analytics, and growth engineering.

What you get: SEO, full site audits and on-page optimisation. Copywriting, landing pages, ads, hooks using direct response frameworks. Email sequences, nurture flows, welcome series, re-engagement. CRO and growth engineering, conversion rate optimisation and A/B strategy. Customer research, analytics, and social media skills included.

TIP: Start with the SEO audit skill, type "run a full SEO audit on this page" and Claude will apply the full methodology without any additional prompting.

npx skills add coreyhaines31/marketingskills

github.com/coreyhaines31/marketingskills

Skill 02, UI-UX-Pro-Max

★ 53.3k GitHub stars, Design thinking, not just layout generation

Gives Claude genuine design intelligence, not just the ability to generate layouts, but to understand visual hierarchy, colour psychology, and the reasoning behind UI decisions before writing a single line of code.

What you get: Understands visual hierarchy and colour psychology before building. Applies design tokens, type scale, and spacing systems automatically. Escapes the generic AI aesthetic, output looks designed, not generated. Works across React, HTML, mobile UI, and landing pages.

TIP: When asking Claude to build a UI, describe the product context as well as the component, "build a pricing card for a B2B SaaS product targeting SMEs" gets significantly better output than "build a pricing card".

npx skills add nextlevelbuilder/ui-ux-pro-max-skill@ui-ux-pro-max

Skill 03, superpowers

★ 120k GitHub stars, A complete software development methodology for Claude

An agentic skills framework and software development methodology with 120k GitHub stars. A complete structured approach to how Claude builds software, from planning through to testing and debugging.

What you get: Test-driven development built in, write tests first, Claude builds to pass them. Structured debugging methodology, traces, isolates, and fixes systematically. Plan to execute timeline, scopes any build into milestones before starting. Works across Claude Code, Cursor, Codex CLI, and more.

TIP: Try asking Claude to "plan and build" something rather than just "build" it. With superpowers installed, it will produce a full plan with milestones before writing a single line of code.

npx skills add obra/superpowers

Skill 04, remotion

★ 41k GitHub stars, AI video generation inside Claude Code

Remotion lets you build videos programmatically using React. This skill brings that capability directly into Claude Code, describe your video, Claude writes the React component, and Remotion renders it frame by frame.

What you get: Describe a video in plain English, Claude writes the full Remotion component. Every frame is programmable, animations, transitions, data-driven graphics. Exports to MP4, GIF, or image sequences. Full React ecosystem available.

HEADS UP: Requires Node 18+ and a Remotion project already scaffolded before installing the skill.

npx skills add JonnyBurger/remotion

Skill 05, Agent Skills for Context Engineering

★ 14.4k GitHub stars, Reduce your token usage without losing quality

A comprehensive collection of 13 skills built for context engineering, multi-agent architectures, and production agent systems. The headline feature: significant token reduction through KV caching, same output quality, lower cost.

TIP: The impact is biggest in long Claude Code sessions and multi-step agent workflows.

npx skills add muratcankoylan/Agent-Skills-for-Context-Engineering

Skill 06, find-skills

★ 418k installs, The meta-skill that finds all other skills

The most-installed Claude skill in the ecosystem. It turns Claude into a skills discovery engine, describe what you want to do, and it searches the skills marketplace and recommends the best options to install.

TIP: Install this one first before anything else. It makes finding every other skill on this list, and the 59,000+ not on it, significantly easier.

npx skills add vercel-labs/find-skills

Skill 07, web-design-guidelines

★ 137k installs, An always-on design quality checker

Acts as a permanent design system quality checker, reviewing every UI Claude generates against design best practices and system rules so nothing inconsistent gets through.

NOTE: Pair this with UI-UX-Pro-Max (skill 02) for a complete design stack, Pro-Max handles the creative direction, web-design-guidelines handles the consistency enforcement.

npx skills add vercel-labs/agent-skills@web-design-guidelines

Skill 08, xlsx

★ Official Anthropic, Read, create and edit spreadsheets in plain English

An official Anthropic skill that gives Claude full spreadsheet capability, create new .xlsx files from scratch, read and extract data from existing ones, apply formulas, format cells, and build charts. All in plain English.

TIP: Works best when you describe the business purpose, not just the structure. "Build me a sales tracking sheet with monthly targets and variance columns" gets better output than "make a spreadsheet with three columns".

npx skills add anthropics/skills@xlsx

Skill 09, PDF skill

★ Official Anthropic, Fill, extract, merge and create PDFs directly

Official Anthropic PDF skill. Gives Claude comprehensive PDF capability, fill multiple forms automatically, extract text and tables, merge and split documents, create new PDFs from scratch, and handle form fields.

TIP: For bulk form filling, give Claude a CSV or JSON file with your data alongside the PDF forms. It will map the fields automatically and fill all forms in one pass.

npx skills add anthropics/skills@pdf

Skill 10, PowerPoint skill

★ Official Anthropic, Generate and edit presentations in plain English

Official Anthropic PowerPoint skill. Lets Claude generate complete slide decks from a brief, edit existing presentations by description, restyle layouts, add or remove slides, and restructure content.

NOTE: For editing existing presentations, place the .pptx file in your project directory before asking Claude to make changes.

npx skills add anthropics/skills@pptx

Skill 11, Word Document skill

★ Official Anthropic, Create and edit Word documents in plain English

Official Anthropic Word document skill. Claude can create formatted documents from scratch, edit and restructure existing .docx files, apply styles, headings, tables, and tracked changes, all from a plain English description.

TIP: This skill handles tracked changes properly, if you ask Claude to "edit this contract to extend the payment terms to 60 days", it will make the change using Word's tracked changes format so you can review and accept.

npx skills add anthropics/skills@docx

Skill 12, software-architecture

★ Community, Clean Architecture and SOLID principles built in

Implements established software design patterns, Clean Architecture, SOLID principles, and comprehensive best practices, directly into how Claude structures and builds code.

TIP: Pair this with the superpowers skill (skill 03) for a full engineering methodology stack, superpowers handles the TDD workflow, software-architecture handles the structural patterns.

npx skills add ComposioHQ/awesome-claude-skills@software-architecture

Skill 13, mcp-builder

★ Community, Build MCP servers from inside Claude

Guides Claude through creating high-quality MCP (Model Context Protocol) servers for integrating external APIs and services. If you want Claude to connect to any tool or service, this skill builds the bridge.

HEADS UP: MCP servers require a host environment to run, Claude Code, Claude Desktop, or a custom deployment. Review the Anthropic MCP documentation at docs.anthropic.com before deploying any MCP server in production.

npx skills add anthropics/skills@mcp-builder
