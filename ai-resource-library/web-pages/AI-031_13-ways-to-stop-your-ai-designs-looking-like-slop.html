The Three Sites, Design References That Do the Work For You

1, Efford, efford.co

Go to efford.co and pick whatever you're building. It gives you a categorised library of real design styles. Find one you like, then copy either the prompt or the actual code directly from the page.

The prompt goes straight into Claude, Codex, or Cursor. The code goes into your editor as a starting point. Either way, you're not designing from scratch. You're telling the AI to replicate something that already looks good.

2, Newform

Newform has one of the longest lists of quality UI components you'll find free. Find the component or layout you want and you'll get two options: save the skill file or download the design.md file. The skill file installs into Claude Code. The design.md file gets dropped into your project root or pasted directly into your prompt. Claude reads it and uses it as a reference. Everything it builds after that pulls from real patterns instead of guessing.

3, SuperDesign

SuperDesign lets you browse design styles visually. Click a style you like and it gives you either a full prompt for the whole page or a more targeted prompt for a specific section. Useful when you only want to fix one part of a design. Copy the prompt, paste it into your AI editor with your project context, and tell it to follow the style exactly.

All three sites work the same way at the core. They give you a prompt, a design.md file, or actual code. You attach it to your AI editor and tell it to build exactly to that reference. That single instruction is what separates a slop output from something that looks designed.

Tips 4 5

4, Install a UI Design Skill

A design skill is a folder with a SKILL.md file that gives Claude an actual design system to work from. Layout rules, spacing principles, component patterns, all loaded automatically every time you start a session. Without one, Claude is guessing at what good design looks like. With one, it has a reference.

The UI UX Pro Max skill on GitHub is the best free option right now. It covers design tokens, colour systems, typography pairing, and component patterns. Download it, zip the folder, and upload it via Settings > Capabilities > Skills in claude.ai.

TIP: For Claude Code, drop the SKILL.md into your project root and rename it CLAUDE.md. It loads at the start of every session without you doing anything.

5, Give Claude a Real Design Reference Every Time

The single most effective thing you can do in any design prompt is attach a reference. Before you write a word about what you want, find a site or component you like and either paste the URL or paste the code. Then say: build to this standard.

Claude is far better at matching than it is at inventing. If you describe what you want in abstract terms you'll get a generic output. If you show it what you want you'll get something close to it. Reference first, instructions second.

Tips 6 7

6, Install Two MCPs: Google Stitch and Nano Banana 2

These two MCP servers give Claude Code access to real design pattern libraries. Instead of generating from memory, it pulls from proven patterns when it builds components. Install both with:

claude mcp add google-stitch claude mcp add nano-banana-2

Verify they're active with claude mcp list. The difference shows up most in layouts and spacing.

7, Connect 21st.dev for Components

21st.dev is a component library Claude Code taps directly. It has 3D elements, animated components, and reactive UI assets. Create a free account, grab your API key from the dashboard, then install it:

claude mcp add 21st-dev --api-key YOUR_API_KEY_HERE

When you ask for anything animated or 3D, Claude pulls a real component instead of attempting to write one from scratch. Keep the key out of any shared files or Git commits.

Tips 8 9

8, Stop Describing, Start Specifying

Most prompts that produce bad design look like this: "Build me a clean, modern landing page with good spacing and a professional colour scheme." That gives Claude nothing to work with. Every word in that prompt is vague. Clean means a hundred different things. Modern is not a design instruction.

Better prompt:

Build a landing page hero section. Dark background, #0D1117. Headline in white, 64px, semi-bold. One line subheadline in #8B949E. Single CTA button, teal, pill shape. Left-aligned text. Right side is a mockup image placeholder. No shadows. No gradients. Tight layout.

Specific beats descriptive every time. If you can measure it, include it. If you can name the colour, name it.

9, Use Canva's Native Connector for Digital Products

If you're building guides, ebooks, or any digital product, you don't need to design from scratch. Enable the Canva connector in Claude settings, start a new chat, turn it on, and Claude can create and edit Canva designs directly without you switching tabs.

Get Claude to write the content first, then ask it to format it into page-sized blocks with one title, one short paragraph, and no more than five bullet points per page. That consistent structure is what lets you move fast.

Tips 10 11

10, Use Claude Projects to Carry Your Design Standards

Every time you start a new conversation without a project, Claude has no idea what your design preferences are. You explain the same things again. The output regresses to the mean.

Set up a Claude project for design work. In the custom instructions, include your colour palette, font choices, spacing rules, and any design standards you want applied consistently. Upload example designs you like as reference files. Every conversation inside that project starts with all of that already loaded.

11, Tell Claude What Not to Do

Banning specific things is more effective than describing what you want. If you're getting AI-looking designs, add these to your project instructions or your prompt:

No drop shadows. No gradients unless specified. No rounded corners above 8px. No stock illustration-style icons. No generic hero with a floating mockup on the right unless I ask. No footer with four columns of links unless I ask.

The defaults Claude reaches for when uninstructed are the same defaults that make AI design look like AI design. Removing them forces it to make deliberate choices instead.

Tips 12 13

12, Ask Claude to Critique the Design First

Before you iterate on a bad output, ask Claude to critique it. Paste the code back in and say: what would a senior product designer change about this? Tell me the five biggest problems with the layout and hierarchy.

Claude is often better at diagnosing design issues than it is at preventing them in the first generation. Get the diagnosis, then fix each issue in the next prompt. This two-pass approach produces better results than trying to write a perfect first prompt every time.

13, Use the Reusable Prompt Formula for Any Product

For anything you're building to sell or distribute, this structure covers every type:

Create a [product type] for [specific audience] who want to [specific outcome]. Make it [number] pages. Tone: [tone]. Structure each page with a title, a short intro paragraph, and bullet points. Format it ready to drop into Canva.

Swap the brackets. Run the prompt. Then ask Claude to break the output into individual pages, each with the same shape, before you go near a design tool. That consistency is what makes the design step fast.

Most people who read a guide like this never apply it. Don't be that person. Pick the three tips that are most relevant to what you're building right now and use them today. The difference between your current outputs and properly designed outputs is a single reference and a specific prompt.
