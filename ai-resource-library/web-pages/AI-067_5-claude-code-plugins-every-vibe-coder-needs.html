Chapter 01: Why These Five

Vibe coding moves fast because the AI is doing the typing. It breaks down for the same reason: the AI is guessing. Guessing at your database schema. Guessing whether the login form it just wrote is actually secure. Guessing what the page looks like once it renders, because it can't see a browser. Guessing at a library's API from training data that's already out of date.

Each plugin below closes one of those gaps. None of them make Claude Code smarter: they give it a capability it doesn't have by default: a live connection to a database, a real browser, a security tester, a way to see another site's design system, and a way to read current docs instead of stale ones.

Plugin 01 · Database: Supabase

Build and manage a database without leaving your terminal

Supabase gives Claude Code a direct line into your project's database, authentication and storage. Once it's connected, you can ask it in plain English to run a SQL query, write a migration, add a column, generate TypeScript types from your schema, or check the logs on an Edge Function, all without opening the Supabase dashboard.

What it does

  • Runs SQL queries and migrations against your project
  • Manages auth providers and storage buckets
  • Generates TypeScript types straight from your schema
  • Reads Edge Function logs when something breaks

Install

# Add Anthropic's official plugin marketplace, then install
claude plugin marketplace add anthropics/claude-plugins-official
claude plugin install supabase@claude-plugins-official

# Restart the plugin system
/reload-plugins

claude.com/plugins/supabase

Try this prompt: "List all my Supabase projects, then run a SQL query to show me all users created this month." That's a good first prompt to confirm the plugin is actually connected before you build anything on top of it.

Plugin 02 · Security: Strix

An open-source AI hacker that pentests your app for you

Strix runs autonomous AI agents that behave like real attackers, they execute your code, probe it for vulnerabilities like SQL injection, broken access control and XSS, and confirm every finding with a working proof-of-concept exploit instead of a "possible issue" guess. Point it at a local folder, a GitHub repo or a live URL and it hands back validated findings with fix guidance.

What it does

  • Tests for OWASP Top 10 issues: IDOR, SQLi, XSS, SSRF and more
  • Every finding ships with a reproducible proof-of-concept
  • Installs as an agent skill Claude Code can call directly
  • Can run in CI to block vulnerable pull requests

Install (agent skill for Claude Code)

npx skills add usestrix/strix
Note

Running a full local scan needs Docker plus an LLM API key of your own (Strix's agents make their own model calls, set via STRIX_LLM and LLM_API_KEY). If you'd rather skip local setup, the hosted platform at app.strix.ai runs the same engine without Docker.

strix.ai · github.com/usestrix/strix

Plugin 03 · QA / Testing: Playwright CLI

Gives your AI a real browser to test what it just built

Playwright CLI is a command-line interface for browser automation, built by the Playwright team specifically for coding agents. Once it's installed, Claude Code can open a real browser, click through the app it just generated, take screenshots, and read back console errors and network requests, catching broken flows before you ever look at the screen yourself.

What it does

  • Navigates, clicks, fills forms and uploads files
  • Screenshots full pages or a single element
  • Reads console messages and network requests back to your AI
  • Runs headless by default, or headed so you can watch it work

Install

npm install -g @playwright/cli@latest

# Installs the skill so Claude Code picks up its commands automatically
playwright-cli install --skills

playwright.dev/docs/getting-started-cli

Try this prompt: "Test the sign-up flow on localhost:3000 using playwright-cli. Take screenshots of every step and flag anything that looks broken." Claude reads its own screenshots back, so it catches layout bugs you'd otherwise only spot by opening the browser yourself.

Plugin 04 · Design: SkillUI

Reverse-engineers any website's design system into a Claude-ready skill

Point SkillUI at any URL, GitHub repo or local project and it crawls it, extracting the exact colour palette, typography scale, spacing system, fonts and component patterns: pure static analysis, no AI model or API key involved. Everything gets packaged into a folder with a CLAUDE.md and SKILL.md file that Claude Code reads automatically, so it can build new pages in that exact style.

What it does

  • Extracts colours, type scale, spacing and fonts from any site
  • "Ultra" mode adds scroll screenshots and animation detection
  • Also scans a local folder or clones a public repo directly
  • Outputs a folder Claude Code loads automatically on open

Install & run

npm install -g skillui

# Extract a design system from any site
skillui --url https://example.com

# Open the output folder and let Claude build in that style
cd example-design && claude

skillui.vercel.app · github.com/amaancoderx/npxskillui

Try this prompt: Run skillui --url against a site you admire, open the output folder in Claude Code, then just ask: "Build me a landing page that matches this design system." It already has the exact colours, type and spacing: it doesn't need you to describe the look.

Plugin 05 · Documentation: Context7

Feeds your AI current docs so it stops guessing at APIs

LLMs are trained on a snapshot of the internet, so fast-moving libraries drift out of date quickly: APIs get hallucinated, examples reference versions that no longer exist. Context7 fixes that by pulling live, version-specific documentation and code examples straight from the source and dropping them into the conversation the moment you ask for setup or configuration help, so Claude Code stops guessing.

What it does

  • Pulls current, version-matched docs for the library you're using
  • Triggers with a simple "use context7" in your prompt
  • No tab-switching to go find the docs page yourself
  • Works across thousands of actively maintained libraries

Install

claude mcp add --transport http context7 https://mcp.context7.com/mcp
Note

Free to use without an API key. Add one at context7.com/dashboard for higher rate limits and access to private repositories.

context7.com

Try this prompt: "Create a Next.js middleware that checks for a valid JWT in cookies. Use context7." Adding "use context7" to any setup or configuration question tells Claude to pull the current docs before it answers, instead of writing from memory.
