How This Guide Works: The Right Tool, Not Just a Chat Message

Every one of these nine jobs can technically be done in a plain Claude chat. But a plain chat forgets everything the moment you close it. The professional you're replacing didn't just answer a question once, they held context, worked from live information, produced a real document, or checked in on you over time. So each build here uses whichever actual Claude feature does that.

Build 01 of 09: Interior Designer

Built with: Claude Projects

Replaces: a paid design consultation

Give it your space, budget, and taste. It designs a full layout with a colour palette and real furniture picks that actually work together.

Why this tool: This is a project, not a one-off question. You'll come back to it as the room evolves, and Claude needs your photos and budget on hand every time, not re-explained each chat.

You'll need: Any Claude account. Free plans get 5 projects; paid plans (Pro/Max/Team) hold a much larger knowledge base.

The Build

  1. Create the project: In claude.ai, click "Projects" in the left sidebar, then "Create project." Name it something specific, like "Living Room Redesign."
  2. Set the project instructions: Open Project instructions and paste the block below. This is what makes every chat inside the project act like a designer, not a generic assistant.
  3. Upload your knowledge: Add photos of the actual room, a folder of inspiration images, and your budget as Project knowledge. Claude references these automatically.
  4. Start a new chat inside the project: Describe the room and what you want. Claude already has your instructions and files loaded.

Paste into: Project Instructions

You are acting as my interior designer. Every time I describe a room, give me:
1) a full layout explaining where each piece of furniture goes and why, 2) a
colour palette for walls and textiles, 3) specific, real, buyable furniture
picks that fit my stated budget. Ask for the room's dimensions and which way it
faces if I haven't given them.

Tip: Upload real photos of the room to Project knowledge. Claude designs around the actual space, not a generic one.

Build 02 of 09: Copywriter

Built with: Claude Skills

Replaces: a freelance copywriter

Give it your offer and audience. It writes conversion-focused copy and stress-tests it against objections until it actually sells.

Why this tool: This is a repeatable process you'll run on every offer you ever write, not a one-time job. A skill teaches Claude the process once, and it applies automatically in any chat from then on.

You'll need: Any Claude plan, with Code execution and file creation turned on in Settings.

The Build

  1. Open Skills settings: Go to Settings → Customize → Skills (or claude.ai/settings/customize-skills).
  2. Create a new skill: Click the "+" button, then "+ Create skill," then choose "Write skill instructions." No file to prepare.
  3. Paste the instructions and name it: Paste the block below and name it something like "Conversion Copy Reviewer." Save it.
  4. Turn it on: Uploaded skills are off by default. Toggle it on in your skills list.
  5. Use it in any chat: Paste your offer and audience. The skill loads automatically because the request matches it.

Paste into: Write Skill Instructions

Use this skill whenever asked to write or review sales, landing page, or ad
copy. Write conversion-focused copy for the stated offer and audience. Then, in
a second pass, list the top 5 objections a skeptical buyer would raise and
rewrite the copy to pre-empt each one. Never skip the objection pass.

Tip: The description field is what makes a skill fire automatically. Name the exact situations it should trigger on.

Build 03 of 09: Travel Agent

Built with: Claude in Chrome

Replaces: a travel planning service

Tell it your destination and budget. It builds a real itinerary with pacing, hidden gems, and backup plans, not just a list of sights.

Why this tool: A good itinerary needs what's actually live on booking and review sites right now, not what Claude remembers from training. Claude in Chrome reads the real page in front of you as you browse.

You'll need: A paid Claude plan (Pro, Max, Team, or Enterprise) and Google Chrome on desktop.

The Build

  1. Install the extension: Open the Chrome Web Store, search "Claude," and click "Add to Chrome."
  2. Sign in: Sign in with your Claude account when prompted. This requires a paid plan.
  3. Open the side panel: Click the Claude icon in your Chrome toolbar. It stays open while you browse.
  4. Browse, then ask: Open real listings, review sites, or a map of your destination, then ask Claude in the side panel to build the itinerary from what's on the pages.
  5. Approve site access: Claude asks before it acts on a page. Approve the sites you want it reading.

Say this in the side panel

I'm going to Lisbon for 5 days on a $1,500 budget. Look at what's actually on
this page and build me a realistic day-by-day itinerary with pacing, a few
local spots, and a backup plan for each day in case of rain or closures.

Tip: Browse to a few real listings first. Claude in Chrome works from what's actually on your screen, not just memory.

Build 04 of 09: Language Tutor

Built with: Claude Mobile App + Memory

Replaces: 1:1 language tutoring

Practice full conversations with it in any language. It catches your specific error patterns and adapts lessons to what you're actually struggling with.

Why this tool: Tutoring only works if it happens often and short, in the gaps in your day, and if Claude remembers your recurring mistakes between sessions instead of starting fresh every time.

You'll need: The Claude app for iOS or Android, with Memory turned on in Settings.

The Build

  1. Get the app: Download Claude from the App Store or Google Play and sign in with your account.
  2. Turn on Memory: In Settings, enable "Generate memory from chat history" so Claude carries context between sessions.
  3. Start a conversation: Ask Claude to role-play a real scenario in your target language.
  4. Ask for the error summary: After a real back-and-forth, ask Claude to summarise the specific patterns it noticed.
  5. Come back tomorrow: Open the app again. Claude already knows what you struggle with.

Try this prompt

Let's have a conversation in Spanish about ordering food at a restaurant. Stay
in character as the waiter. Correct my grammar as we go, and at the end, tell
me the specific error patterns you noticed and how to fix them.

Tip: Ask for the error-pattern summary explicitly. Left alone, Claude will just keep chatting.

Build 05 of 09: Social Media Manager

Built with: Artifacts (persistent storage)

Replaces: a social media management retainer

Give it your brand and niche. It builds your content strategy, hooks, and posting cadence, then sharpens it based on what's working.

Why this tool: A content calendar needs to persist and get checked off over weeks, not live in a chat message you'll lose. Artifacts can save your data so it's still there the next time you open it.

You'll need: Any Claude plan, in a normal chat or inside a Project.

The Build

  1. Open a chat: A Project is a nice extra here if you want your brand knowledge attached, but a normal chat works fine.
  2. Describe your brand: Give Claude your brand, niche, and how often you can realistically post.
  3. Ask for a saved artifact: Ask Claude to build the calendar as an interactive artifact that saves your data, not just a text list.
  4. Use it, then report back: Check posts off as you go. After a couple of weeks, tell Claude what actually performed.
  5. Ask it to sharpen the plan: It updates both the strategy and the saved calendar based on real results.

Try this prompt

Build me an interactive content calendar as an artifact I can check off as I
post, with pillar topics, hook formulas, and a posting cadence for my skincare
brand. Save my data so it's there when I reopen it.

Tip: This uses Claude's persistent storage inside Artifacts. Your data lives in the artifact itself, not in the chat.

Build 06 of 09: Personal Trainer

Built with: Claude Cowork

Replaces: a personal training package

Tell it your goals, your gym or home setup, and your free days. It builds the plan and levels it up each week.

Why this tool: This is a multi-step, ongoing job, not a single question: build a plan, produce a way to track it, then revise it weekly. Cowork is built for handing off exactly that kind of work.

You'll need: A paid Claude plan and the Claude Desktop app.

The Build

  1. Get the desktop app: Download Claude Desktop from claude.com/download and sign in.
  2. Open Cowork: Click the "Cowork" tab in the desktop app.
  3. Hand off the build: Describe your goal, equipment, and free days, and ask for a 4-week plan plus a simple file to track it in.
  4. Let it run: Cowork works the task in the background and hands you back the plan and a tracking file.
  5. Check in weekly: Feed it how sessions actually went. Ask it to adjust before it builds the next week.

Try this prompt

My goal is to build muscle. I have dumbbells and a pull-up bar at home, and I
can train Monday, Wednesday, Friday, and Saturday. Build me a 4-week
progressive plan and a simple file to track it in, then check in with me each
week to adjust it.

Tip: Cowork works best when you hand off the task and let it run, rather than chatting turn by turn.

Build 07 of 09: Business Coach

Built with: Claude for Excel

Replaces: a business coaching retainer

Give it your numbers and bottleneck. It diagnoses what's actually holding growth back and pressure-tests your next move like a real operator.

Why this tool: A real diagnosis needs your actual numbers, live, not numbers retyped into a chat. Claude for Excel reads the workbook you're already working in.

You'll need: A paid Claude plan and Microsoft 365 (Excel on web, Windows, or Mac).

The Build

  1. Install the add-in: In Microsoft AppSource, or from Excel's Home → Add-ins menu, search "Claude by Anthropic" and add it.
  2. Sign in: Connect it to your Claude account. This requires a paid Claude plan.
  3. Open your numbers: Have your revenue, churn, CAC, or whatever you track open in the workbook.
  4. Open the Claude sidebar: Use the Add-ins menu, or Ctrl+Alt+C on Windows / Ctrl+Option+C on Mac.
  5. Ask for the diagnosis: Describe your bottleneck. Claude reads the live sheet as it answers.

Try this prompt

Looking at this sheet, my bottleneck feels like new customer acquisition.
Diagnose what's actually holding growth back, then pressure-test my plan to
spend on paid ads before I commit budget to it.

Tip: Claude only sees the workbook that's open. If you're comparing two files, put the numbers in one sheet first.

Build 08 of 09: Resume Writer

Built with: Claude for Word

Replaces: a professional resume writing service

Give it your work history and the job posting. It rewrites your resume to mirror that role's language and beat the ATS.

Why this tool: The output here is the actual document you'll submit. Editing it directly inside Word, formatting intact, beats writing in a chat and reformatting it yourself after.

You'll need: A paid Claude plan and Microsoft 365 (Word).

The Build

  1. Install the add-in: In Word, open the ribbon, click Add-ins, and search "Claude."
  2. Sign in: Connect it to your Claude account. This requires a paid Claude plan.
  3. Open your resume: Have your current resume open in Word, or paste your work history into the sidebar.
  4. Add the job posting: Paste the full posting you're applying to into the sidebar.
  5. Ask for the rewrite: Claude rewrites directly against the open document.

Try this prompt

Here's the job posting I'm applying to: [paste it]. Rewrite this resume to
mirror the language and priorities of the posting and get past ATS keyword
filters, without inventing anything I haven't actually done.

Tip: Always paste the actual posting. A generic "make it better" ask gets a generic result.

Build 09 of 09: Meal Planner & Nutrition Helper

Built with: Claude Code (Desktop)

Replaces: a nutrition coaching subscription

Tell it your macros, allergies, and what's in your fridge. It builds a weekly plan and adjusts it as things change.

Why this tool: "Adjusts as things change" really means a small tool you can rerun any time your fridge changes, not a fresh conversation every week. Claude Code builds that tool for you, no coding required.

You'll need: A paid Claude plan and the Claude Desktop app (Mac or Windows).

The Build

  1. Get the desktop app: Download Claude Desktop from claude.com/download and sign in.
  2. Open the Code tab: Click "Code" at the top of the desktop app.
  3. Describe the tool in plain English: Tell it what you want built. See the prompt below.
  4. Approve as it builds: Claude proposes each change; you approve it. No coding on your end.
  5. Rerun it any time: Update your fridge inventory and ask Claude to regenerate the week's plan.

Try this prompt

Build me a simple personal meal-planning tool. I give it my macro targets,
allergies, and what's currently in my fridge, and it outputs a 7-day plan using
what I have plus a shopping list for the rest. Keep it simple, just something I
can run on my own computer.

Tip: You're not writing code. You're describing what you want and approving Claude's changes as it builds.
