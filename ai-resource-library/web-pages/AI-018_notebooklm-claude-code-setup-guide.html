NotebookLM + Claude Code Setup Guide

Max Johnson @maxjohnscn

NotebookLM + Claude Code. Three Research Agents. One Weekly Prompt. Nobody Else Is Doing This.

NotebookLM is one of the most underrated tools out there. Most people use it on its own. This guide shows you how to connect it directly to Claude Code using notebooklm-py, an unofficial Python API with 6.1k stars on GitHub. Once it is set up, you build three research agents and run a single weekly prompt that most people would not even think to try.

What you will have when this is done:

  • notebooklm-py installed and connected to your Google account
  • The NotebookLM skill installed inside Claude Code
  • Three dedicated research agents, role model, yourself, your business
  • A weekly prompt that queries all three and surfaces what you are missing

Before you start. You need a few things in place before following these steps:

  • Claude Code installed and working on your machine
  • A Google account with access to NotebookLM (notebooklm.google.com)
  • Python 3.10 or later installed on your machine
  • pip installed (comes with Python by default)

NOTE: notebooklm-py is an unofficial API, it works by automating your Google session rather than using an official API key. You will need to authenticate with your Google account during setup.

Step 01, Install notebooklm-py, github.com/teng-lin/notebooklm-py

This is the repo that makes everything possible. It gives Claude Code full programmatic access to NotebookLM, including features the web UI does not expose. 6.1k stars, actively maintained, MIT licensed.

$ Terminal, install notebooklm-py pip install notebooklm

Then authenticate with your Google account:

$ Terminal, authenticate with Google notebooklm auth login # A browser window will open. # Sign in with your Google account and approve access. # Your session token is saved locally, you only do this once.

TIP: If you already use NotebookLM with a Google Workspace account, sign in with that same account. Your existing notebooks will be accessible immediately after authentication.

Step 02, Install the Skill into Claude Code, From the notebooklm-py repo

The repo includes a Claude Code skill that lets Claude call NotebookLM directly from the terminal. You do not need to leave Claude Code to query your notebooks, Claude handles it all.

$ Terminal, clone the repo and copy the skill git clone https://github.com/teng-lin/notebooklm-py.git # Copy the skill into your project's .claude-plugin folder cp -r notebooklm-py/skills/notebooklm \ ./your-project/.claude-plugin/notebooklm

TIP: If your project does not have a .claude-plugin folder yet, create one in the project root first: mkdir .claude-plugin

Step 03, Create Your Three Research Agents in NotebookLM, The setup most people skip

Go to notebooklm.google.com and create three separate notebooks. Each one becomes a dedicated research agent with a specific focus. The more you put in, the more useful the output.

Agent 01, Role Model. Create a notebook and upload everything you can find on the person whose thinking you want to understand. Interviews, books, essays, transcripts, podcast episodes. The more depth the better. Name the notebook: Role Model, [their name].

Agent 02, Yourself. Create a second notebook and upload your own writing. Strategy documents, past decisions, notes, voice memos you have transcribed, anything that captures how you think. Name it: Research Agent, Myself.

Agent 03, Your Business. Create a third notebook and upload everything about your market. Competitor websites, customer research, industry reports, your own product documentation. Name it: Research Agent, [your business name].

TIP: NotebookLM accepts PDFs, Google Docs, text files, and website URLs. For the role model agent, pasting article URLs is the fastest way to get a lot of content in quickly.

NOTE: You do not need to have everything uploaded on day one. Start with what you have and add to each notebook over time. The agents get more useful the more context they have.

Step 04, Run the Weekly Prompt in Claude Code, The prompt that does the work

Once your three agents are set up, open Claude Code and run this prompt. Do it every week. It queries all three notebooks simultaneously and surfaces the gaps between where you are and where you could be.

$ Claude Code, paste this every week Query all three NotebookLM research agents simultaneously. Agent 01 (Role Model): Where would this person do things differently to what I am currently doing? What decisions or approaches of theirs am I not applying right now? Agent 02 (Myself): Where is my current thinking or behaviour drifting from my own stated strategy and values? What patterns am I repeating that I have flagged as problems before? Agent 03 (Business): What are my competitors doing right now that I have not spotted or acted on yet? What does the market data suggest I am underestimating? Synthesise the findings across all three. Surface the top three things I should be paying attention to this week.

TIP: Run this on the same day every week. Monday morning works well, it gives you a clear set of priorities before the week starts rather than reacting to whatever comes in.

WARNING: The quality of the output depends entirely on the quality of what is inside your notebooks. If Agent 02 only has two documents in it, the self-analysis will be shallow. Keep adding to the agents regularly.

Why It Works, Three Perspectives. One Blind Spot Removed.

Most people operate inside one frame of reference, their own. The role model agent forces a second perspective from someone who has already solved problems you are currently facing. The self agent catches you when you drift from your own thinking. The business agent keeps your strategic view honest against what is actually happening in the market.

Running all three together weekly means you are consistently looking at the same situation from three different angles. The gaps it surfaces are the things that would otherwise take months to notice on your own.

TIP: The most valuable output is usually from Agent 02. Most founders already know what their role model would do. Catching the gap between your own stated strategy and your actual behaviour is harder to see without a system like this.
