Command 01, /ultra plan

This command takes whatever you're planning, opens a web session, and puts sub-agents on it. While you're still working in your terminal, it's researching, building assets and diagrams for your plan in the background. You get parallel planning without stopping what you're doing.

What it does:

  • Opens a web research session alongside your terminal
  • Deploys sub-agents to research your plan in parallel
  • Builds assets and diagrams in the background
  • Delivers results while you keep working on other tasks
  • No need to stop, tab out, or break your flow

How to use it:

/ultra plan

Run this inside any Claude Code session.

Command 02, /power up

When you run this command, it creates 10 tailored tutorials on how to use Claude Code. But they're not generic tutorials. They're based on how you've actually been using it. It looks at your history and teaches you the things you specifically need to get better at.

What it does:

  • Analyses your Claude Code usage history
  • Identifies gaps in how you're using the tool
  • Generates 10 personalised tutorials for you
  • Teaches you techniques relevant to your actual workflow
  • Not generic advice, specific to how you work
/power up

Run this inside any Claude Code session.

Command 03, /insights

This command builds a full report on how you use Claude Code. It tells you what you're doing well, what you're doing a lot, and how you can actually do it better. It will call you out for doing things manually that you could have automated.

What the report covers:

  • What you're doing well with Claude Code
  • What tasks you run most frequently
  • Where you're doing things manually that could be automated
  • Specific recommendations to improve your workflow
  • Patterns in your usage you might not have noticed
  • Actionable steps, not just observations
/insights

Run this inside any Claude Code session.
