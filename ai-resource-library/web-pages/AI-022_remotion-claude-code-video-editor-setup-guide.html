Remotion + Claude Code Video Editor Setup Guide.

By the end of this guide you will have Remotion connected to Claude Code and be able to create or edit videos directly from Claude using plain English instructions.

What you'll be able to do:

  • Describe a video in plain English and Claude builds it
  • Reference any video file on your computer for editing
  • Ask for revisions and watch Claude update the editor live
  • No separate editing software required

Requirements:

  • Claude Desktop with Claude Code enabled
  • A computer running macOS or Windows
  • An internet connection for the initial install

Setup, Three Steps to Get Running

Step 1, Open Claude Desktop and switch to Claude Code. Open the Claude Desktop app. In the top navigation, select Code to switch into Claude Code mode. This is where all the setup happens.

TIP: If you do not see a Code tab in Claude Desktop, make sure your app is up to date. Check for updates in the menu bar under Help.

Step 2, Get the Remotion install command. Open a browser and search Remotion. Click the first result, which should be remotion.dev. On the site, find the install command and copy it. It looks like this:

npx create-video@latest

Copy that command. Head back to Claude Code, paste it into the input and press Enter. Claude will handle the rest of the installation automatically.

INFO: The install takes about a minute depending on your connection. Claude will let you know when it is done.

Step 3, Open the Remotion interface inside Claude. Once the install is complete, open a new tab inside Claude Code. In the address bar type:

/remotion video

This opens Remotion's video editor directly inside Claude. You are now ready to create and edit videos.

Using It, Creating and Editing Videos

Creating a new video. Once the editor is open, describe the video you want in plain English. Tell Claude the style, the content, the length. It will start building it out in the editor immediately.

Editing an existing video. To edit a video file from your computer, reference it by file path in your message to Claude. For example:

Edit the video at /Users/yourname/Downloads/myclip.mp4, add text overlays and trim the first 5 seconds

Requesting revisions. If you want changes, just ask. Type your revision instructions in plain English and Claude updates the editor live. There is no need to restart or re-run anything.

TIP: Be specific with your instructions. The more detail you give Claude about what you want, the closer the first result will be to what you are after.

Quick Reference, Commands at a Glance

Install command (run once):

npx create-video@latest

Open the video editor:

/remotion video

Example prompt to create a video:

Create a 30 second intro video with my company name in bold text, dark background, fade in from black

Example prompt to edit a file:

Edit /path/to/video.mp4, add subtitles and remove the last 10 seconds

NOTE: Remotion renders videos using your computer's processing power. Longer or more complex videos will take more time to export.

That is everything. You now have a full AI video editor running inside Claude.
