Run Your Meta Ads Team Inside Claude

Max Johnson@maxjohnscn

Five skills, two MCP layers, and a weekly rhythm that replaces a full Meta ads team inside a single Claude conversation.

Chapter 01: The Setup

Before you touch a single skill, you need four things in place. This is not optional groundwork, it is the foundation that makes everything else work.

  1. A Claude Pro or Team account. Skills require the extended context window and the ability to install custom tooling. The free tier will not cut it here.
  2. MCP enabled in your Claude settings. Go to Settings, then Developer, and switch on Model Context Protocol. This is what allows Claude to connect to live data sources rather than just your chat history.
  3. Node.js 18 or above installed on your machine. Every MCP server in this guide runs on Node. Check your version by running node -v in your terminal. If you are below 18, update before continuing.
  4. Access to Meta Business Manager. You will need admin or advertiser-level permissions on the ad accounts you want to connect. If you are working for a client, make sure they have added you before you attempt the connection steps in Chapter 02.
Reality Check

This setup takes about 45 minutes the first time. Once it is done, the weekly rhythm in Chapter 08 takes under 30 minutes. The front-loading is worth it.

Chapter 02: Connect Meta

There are two distinct MCP layers involved in this system. They serve completely different purposes and you need both of them active at the same time.

LAYER A · PUBLIC — Ad Library MCP

Connects Claude to Meta's public Ad Library. No authentication needed. Lets you search any active ad running on Facebook or Instagram by keyword, brand name, or country. This is your competitive intelligence feed, available to anyone, fully open.

LAYER B · YOUR ACCOUNT — Account MCP

Connects Claude to your private Meta Ads Manager data via the Marketing API. Requires a system user token with ads_read permission. Gives Claude access to your real spend, ROAS, CPMs, CTRs, creative performance data, and campaign structure.

To install both layers, open your terminal and run the following commands one after the other. Replace the placeholder token value with your own Marketing API token from Meta Business Settings.

npx @modelcontextprotocol/create-server meta-ad-library
cd meta-ad-library && npm install

npx @modelcontextprotocol/create-server meta-ads-manager
cd meta-ads-manager && npm install

# Set your token as an environment variable
export META_ADS_TOKEN=your_system_user_token_here
Note

After installation, add both servers to your Claude MCP config file at ~/.claude/mcp.json. Restart Claude after saving. You will see both connections appear in the MCP status panel on the left sidebar once Claude detects them.

Chapter 03 · Skill 1: The Spy Skill

The Spy Skill uses Layer A (the public Ad Library MCP) to systematically scrape your competitors' active creatives and pull structured data back into Claude for analysis. You are not guessing what your competitors are running. You are reading it directly.

How to set it up

  1. Install the skill by going to Claude Skills, searching for "Meta Ad Spy", and clicking Install. It will appear in your skills panel on the left.
  2. Configure your competitor list inside the skill settings. You can add up to 20 page names or Facebook Page IDs. The skill queries all of them in parallel on each run.
  3. Run the skill by typing /spy in any Claude conversation. It will pull all active ads from your competitor list and return a structured table with ad format, copy angle, call to action, estimated run duration, and country targeting.
/spy competitors=["Gymshark","AYBL","Alphalete"] country=GB format=video
# Returns: active video ads from all three brands in the UK market
# Fields: ad_id, brand, headline, body_copy, cta, start_date, formats, placements
Caveat

The Ad Library only shows ads that have been active for at least 24 hours and excludes ads that have been paused for more than 7 days. You will not catch ads that launched and died in under a day, which is actually useful: anything you do see has already proven it can survive the first review cycle.

Chapter 04 · Skill 2: The Bulk Creative Skill

The Bulk Creative Skill takes your spy data and generates 10 complete ad scripts in a single pass. Not 10 variations of one concept. Ten genuinely different angles, each with its own hook, body structure, and call to action.

How to set it up

  1. Install the skill by searching for "Meta Bulk Creative" in the Claude Skills directory. It works alongside the Spy Skill so install both before running either.
  2. Pass your spy output directly into the skill. You do not need to reformat anything. The skill reads the structured table from the Spy Skill and uses it as the creative brief automatically.
  3. Set your brand voice parameters inside the skill config: product name, key benefit, target customer description, and any phrases you never want to use. The skill respects these constraints across all 10 outputs.
/bulk-creative \
  product="Whey protein isolate" \
  benefit="Mixes clean with zero clumping" \
  customer="Men 22 to 35 who train 4 times a week" \
  avoid="game changer, revolutionary, best-in-class" \
  count=10 \
  formats=["UGC hook","Problem-Solution","Testimonial","Before After","Listicle"]
Note

Each of the 10 outputs includes a recommended visual direction in square brackets after the copy. These are written for a human creative director or a video editor to interpret, not for another AI tool. Keep them as notes rather than exact prompts if you are using them with a generation tool.

Chapter 05 · Skill 3: The Ad Score Skill

The Ad Score Skill connects to Layer B (your private account MCP) and scores every creative you have run in the last 30 days against six performance criteria. It tells you not just what performed well but why, in plain language.

How to set it up

  1. Install the skill by searching for "Meta Ad Score" in the skills directory. This skill requires Layer B to be active. It will not work without your account token configured in Chapter 02.
  2. Set your scoring weights in the skill config. The default weights are: Hook Rate 30%, CTR 25%, Thumbstop 20%, ROAS 15%, CPM Efficiency 10%. Adjust these to match your actual business priorities. A high-ticket offer will weight ROAS differently than a lead gen campaign.
  3. Run the skill weekly by typing /score in Claude. It pulls the last 30 days of creative-level data from your account and returns each ad with a score from 0 to 100, a one-line explanation of the primary driver, and a recommended action: scale, test, pause, or kill.
/score \
  account_id=act_123456789 \
  date_range=last_30d \
  min_spend=50 \
  weights={"hook_rate":30,"ctr":25,"thumbstop":20,"roas":15,"cpm":10}
# Returns: sorted table of all creatives with scores, drivers, and recommended actions
Note

Set min_spend=50 (or your own minimum threshold) to filter out ads with too little data to score reliably. Scoring a creative that has spent $4 is meaningless. The default threshold is $50 but raise it to $100 if your daily budget is above $500.

Chapter 06 · Skill 4: The Competitive Ad Extractor

The Competitive Ad Extractor goes deeper than the Spy Skill. Instead of returning a table of what your competitors are running, it breaks down each ad into its structural components so you can extract the pattern, not just the content.

How to set it up

  1. Install the skill by searching for "Meta Ad Extractor" in the skills directory. It requires the Ad Library MCP (Layer A) to be active.
  2. Point it at a specific ad or a brand. You can pass a single Ad Library URL, an array of URLs, or a brand name. When you pass a brand name, it pulls their top 5 longest-running ads automatically, since longevity in the Ad Library is a strong signal of a profitable creative.
  3. Run the extraction with /extract. For each ad, the skill returns: hook type (question, statement, pattern interrupt, social proof), structure (AIDA, PAS, FAB, or other), emotional trigger, objection addressed, and the exact CTA verb used.
/extract \
  brand="Huel" \
  country=GB \
  top_n=5 \
  output=structured
# Returns: structural breakdown of Huel's 5 longest-running UK ads
# Each ad: hook_type, structure, emotional_trigger, objection, cta_verb, run_days
Caveat

The extractor reads copy and infers structure. It is very good at identifying common frameworks but it will occasionally misclassify an ad that uses a hybrid structure. When in doubt, read the raw copy alongside the extraction. The extraction is a starting point, not a verdict.

Chapter 07 · Skill 5: The Ads Meta Skill

The Ads Meta Skill is the connective tissue of the whole system. It takes the outputs from all four previous skills and synthesises them into a single weekly brief: what your competitors are doing, what your own best work looks like, where the gaps are, and what to test next.

How to set it up

  1. Install the skill by searching for "Ads Meta Skill" in the skills directory. This is the last skill to install because it depends on the outputs from the other four. It requires both Layer A and Layer B to be active.
  2. Run it last every week. The skill pulls the most recent outputs from your Spy, Score, and Extractor runs automatically. You do not need to copy and paste anything between skills. The Meta Skill reads them from your Claude session history.
  3. Use the output as your creative brief for the week. The final output is a 3-section brief: Top 3 competitive patterns observed, Top 3 performing angles from your own account, and 5 recommended test concepts with rationale for each one.
Note

The Ads Meta Skill works best when all four preceding skills have been run in the same Claude session. If you run them across separate sessions, paste the outputs into a new session before running /meta-brief. Claude's context window is large enough to hold all four outputs simultaneously at Pro tier.

Chapter 08: Run The Full Stack

Here is how the five skills fit into a repeatable weekly rhythm. Run them in this order every week and you will have a complete competitive and creative picture in under 30 minutes.

MON
Spy on competitors
Skill 1: The Spy Skill

Run /spy first thing Monday. Pull all active ads from your competitor list and save the output. This gives you a snapshot of what launched over the weekend, which is when most brands push new creative.

EXT
Extract the patterns
Skill 4: The Competitive Ad Extractor

Immediately after spying, run /extract on the top 3 brands from your spy output. You want the structural breakdown before you start writing anything. This takes about 5 minutes.

WRI
Write 10 new concepts
Skill 2: The Bulk Creative Skill

With the spy data and extraction in your session, run /bulk-creative. The skill reads both automatically. You will have 10 complete ad scripts ready in under 2 minutes. Review and edit before sending to production.

SCO
Score last week's work
Skill 3: The Ad Score Skill

Run /score to see how last week's creatives performed. Pause anything below 40. Flag anything above 70 for scaling. The score output feeds directly into the Meta Skill brief so run this before /meta-brief.

MTH
Monthly brief and strategy reset
Skill 5: The Ads Meta Skill

Run /meta-brief to synthesise everything into a single weekly brief. On the last Monday of the month, add the flag --monthly and the skill will also generate a 30-day retrospective and a 4-week testing calendar for the month ahead.

Keep It on a Leash

Claude is fast. That is both the point and the risk. The Bulk Creative Skill can generate 50 ad scripts in the time it used to take to write one. Resist the temptation to flood your account with untested creative. Pick 3 concepts from each weekly run, test them properly with a controlled budget, and let the Score Skill tell you what to scale. Volume without discipline is just expensive noise.
