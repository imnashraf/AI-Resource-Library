Claude Code Design Stack Setup Guide

Max Johnson @maxjohnscn

Three tools. Installed once. Your Claude Code goes from decent to professional-grade designer. Follow this guide in order, the whole thing takes about 15 minutes.

The Stack:

  • 01 GitHub, UX/UI Design Skill: Gives Claude a real design system to work from. Actual UI principles, not just aesthetics. Claude reads it automatically in every session.
  • 02 MCP, Google Stitch + Nano Banana 2: Real design pattern references. Claude stops guessing and starts pulling from proven patterns when it builds for you.
  • 03 Library, 21st.dev: Premium 3D and reactive component assets Claude Code taps directly. The difference in output quality is immediate.

Before You Start. Make sure you have Claude Code installed and working on your machine, and Node.js version 18 or higher. Run the commands below to check.

# Check your versions node --version npm --version claude --version

TIP: No Claude Code yet? Install it with: npm install -g @anthropic-ai/claude-code, then authenticate with your Anthropic account.

Step 01, Install the Pro UX/UI Design Skill from GitHub, Free

A CLAUDE.md skill file that gets added to your project. Gives Claude Code a proper design system, layout principles, component patterns, spacing rules, baked in from the start.

Navigate into your project folder first, then run the command below to download the skill file.

# Navigate to your project cd your-project-folder # Download the UX/UI skill into your project root curl -O https://raw.githubusercontent.com/[repo-link]/main/CLAUDE.md

NOTE: Claude Code automatically reads any CLAUDE.md file in your project directory. Once this is in place, the design system loads automatically every time you start Claude Code in this project. No extra steps after install.

Step 02, Install Google Stitch MCP + Nano Banana 2, Free

MCPs give Claude access to external references. These two give it real design patterns to pull from when building. Install both using Claude Code's built-in MCP installer.

# Install Google Stitch MCP claude mcp add google-stitch # Install Nano Banana 2 MCP claude mcp add nano-banana-2

TIP: Verify both installed correctly by running: claude mcp list, you should see both listed as active.

Step 03, Connect the 21st.dev Asset Library, Free tier available

21st.dev is a component library Claude Code taps directly, 3D elements, animated components, reactive UI. Create a free account at 21st.dev, grab your API key from your dashboard, then run the install below.

# Replace YOUR_API_KEY_HERE with your key from 21st.dev claude mcp add 21st-dev --api-key YOUR_API_KEY_HERE

WARNING: Keep your API key private. Do not paste it into shared files or commit it to Git. This command stores it securely in your local Claude Code config.

Step 04, Test the Full Stack, Verification

Open Claude Code in your project and paste the prompt below. If all three tools are working, Claude will pull from the design skill, reference real patterns via the MCPs, and use a 21st.dev component for the 3D element.

Test prompt, paste into Claude Code:

Build me a landing page hero section with a 3D animated gradient background, a bold headline, a subheadline, and a CTA button. Use 21st.dev components for the 3D elements. Follow the UX/UI design skill guidelines for layout and spacing. Reference best-practice hero patterns from Stitch and Nano Banana.

TIP: Good output: Claude references the design skill without prompting, pulls a real layout pattern, and uses an actual 21st.dev component for the 3D element. If any of those are missing, check which tool didn't install using: claude mcp list
