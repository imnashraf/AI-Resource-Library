## 1. What This Resource Teaches  
This tutorial walks a newcomer through the creation of a professional‑grade design environment for Claude Code. It explains how to enrich Claude’s native capabilities with three complementary assets: a GitHub‑hosted UX/UI design skill, two Model‑Component‑Providers (MCPs) that supply vetted layout patterns, and a third‑party 3D component library. By the end of the guide, the learner can spin up a Claude Code session that automatically draws from a structured design system, references proven UI patterns, and injects high‑fidelity 3D widgets without additional prompting.

The underlying architecture is a lightweight stack that leverages Claude’s ability to ingest a `CLAUDE.md` file placed in the project root, and to resolve external MCPs via the `claude mcp` CLI. The guide also demonstrates a quick verification step—issuing a single design prompt and confirming that Claude synthesizes output from all three sources. The process is designed to be repeatable across projects, requiring only a one‑time installation of each component.

## 2. Why It Matters  
Embedding a formal design system directly into Claude Code eliminates the trial‑and‑error loop that typically occurs when AI generates UI mock‑ups. The design skill supplies concrete spacing, typography, and component conventions, ensuring visual consistency. The MCPs (Google Stitch and Nano Banana 2) act as curated pattern libraries, steering Claude toward industry‑standard hero sections, navigation bars, and other common constructs. Finally, the 21st.dev asset library adds production‑ready 3D and animated elements, raising the perceived quality of generated prototypes.

Collectively, the stack reduces iteration time, cuts down on manual post‑processing, and aligns AI‑generated assets with brand guidelines. For teams that rely on rapid prototyping or low‑code UI generation, this setup translates into faster stakeholder reviews, fewer redesign cycles, and a smoother handoff to developers.

## 4. Key Concepts & Principles  
- **Design Skill Ingestion (`CLAUDE.md`)**: A markdown‑style configuration that Claude reads automatically at runtime, embedding a full design system (layout grids, spacing tokens, component definitions) into every session.  
- **Model‑Component‑Provider (MCP)**: A plug‑in mechanism that registers external pattern libraries with Claude, enabling the model to reference concrete UI templates rather than improvising.  
- **Secure API Key Management**: When connecting to third‑party asset services (e.g., 21st.dev), the key is stored in Claude’s local configuration, preventing accidental exposure in source control.  
- **Verification Prompt**: A single, comprehensive design request that serves as a functional test, confirming that the skill file, MCPs, and asset library are all active and correctly linked.

## 5. Tools & Technologies Mentioned  
- **Claude Code (`@anthropic-ai/claude-code`)** – The command‑line interface that powers AI‑driven code and UI generation; it reads `CLAUDE.md` files and resolves MCPs.  
- **Node.js (v18+)** – Runtime environment required for the Claude CLI and for executing the `npm` installation commands.  
- **GitHub** – Host for the open‑source UX/UI design skill file; the guide uses `curl` to fetch the raw markdown into the project.  
- **Google Stitch MCP** – A pattern repository that supplies best‑practice hero and layout structures.  
- **Nano Banana 2 MCP** – Another curated pattern set focusing on modern UI components and interaction flows.  
- **21st.dev Asset Library** – A marketplace of premium 3D models and reactive UI widgets that Claude can embed directly via an API key.

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Rapid Hero Section Prototyping  
1. **Prepare the project**: `cd` into the target folder and ensure Node.js ≥ 18 is installed.  
2. **Add the design skill**: `curl -O https://raw.githubusercontent.com/<repo>/main/CLAUDE.md`.  
3. **Install MCPs**:  
   ```bash
   claude mcp add google-stitch
   claude mcp add nano-banana-2
   ```  
4. **Connect 21st.dev**: Obtain an API key from the 21st.dev dashboard, then run  
   ```bash
   claude mcp add 21st-dev --api-key <YOUR_API_KEY>
   ```  
5. **Validate**: `claude mcp list` should list all three providers.  
6. **Generate**: Launch Claude Code in the folder and issue the prompt:  
   *“Create a landing‑page hero with a 3D animated gradient background, bold headline, sub‑headline, and CTA button. Use 21st.dev for the 3D element, follow the design‑skill spacing, and apply Stitch/Nano Banana patterns.”*  
7. **Inspect**: Verify that the output references the design skill (e.g., spacing tokens), includes a Stitch‑derived layout, and embeds a 21st.dev component tag.

### Use Case 2 – Consistent Component Library Expansion  
1. **Create a new component repo** and place a `CLAUDE.md` file that defines the component’s visual language.  
2. **Add MCPs** once at the global level (they persist across projects).  
3. **Register a secondary asset source** (e.g., a custom 3D asset service) using the same `claude mcp add` syntax with its own API key.  
4. **Run a batch generation script** that iterates over a list of component names, feeding each to Claude with a prompt like:  
   *“Generate a reusable card component that follows the design‑skill grid, uses Nano Banana’s card pattern, and includes a 21st.dev animated icon.”*  
5. **Collect outputs** into a shared component library, ensuring each artifact adheres to the same design system without manual tweaking.

## 7. Prerequisites  
- Node.js version 18 or newer installed locally.  
- Global installation of the Claude Code CLI (`npm install -g @anthropic-ai/claude-code`).  
- An active Anthropic account for authentication.  
- Internet access to fetch the GitHub skill file and to register MCPs.  
- Optional but recommended: a free 21st.dev account to obtain an API key for 3D assets.
