## 1. What This Resource Teaches  
This guide walks the reader through a data‑driven pipeline that turns raw short‑form video performance metrics into a concrete, repeatable content plan. It begins by exposing the limitations of manual “scroll‑and‑guess” research and then introduces Sandcastles—a platform that continuously harvests videos from Instagram, TikTok, and YouTube, scores each clip against its channel’s baseline, and supplies full transcripts with granular hook/format annotations.  

The core technical mechanic is the **MCP (Message‑Connector‑Protocol) bridge** that links Sandcastles to Claude, the Anthropic large‑language model. Once the connector is authorized, Claude can request structured JSON payloads (watchlist entries, outlier rankings, transcript blocks) and run natural‑language prompts that automatically surface patterns such as dominant hook types, optimal video lengths, or recurring storytelling structures. The final segment shows how to translate those insights into a three‑step workflow: (1) pull the outlier set, (2) distill the common signals, and (3) generate a batch of video ideas that inherit the proven hooks and formats.

## 2. Why It Matters  
In the fast‑moving short‑form ecosystem, a single viral hook can dominate a niche for weeks, yet traditional research methods miss these signals because they rely on anecdotal observation of a handful of videos. Sandcastles quantifies “what works” by computing an **outlier score**—a statistical deviation from a channel’s average engagement—thereby surfacing the true performance drivers. By feeding this structured data into Claude, creators obtain **AI‑augmented pattern recognition** without writing custom code or exporting CSVs. The result is a measurable reduction in research time (often >1 hour per day) and a higher probability that the next piece of content will replicate the identified success factors. For teams that need to scale content output across multiple platforms, the approach replaces guesswork with a repeatable, data‑backed decision loop.

## 4. Key Concepts & Principles  

- **Outlier Scoring** – A normalized metric that flags videos performing significantly above a channel’s historical average, allowing the system to focus on genuine spikes rather than raw view counts.  
- **Watchlist Architecture** – A unified repository within Sandcastles where any Instagram, TikTok, or YouTube channel can be added; the service continuously monitors new uploads and updates the outlier ranking in near‑real time.  
- **MCP Connector Pattern** – The Message‑Connector‑Protocol enables Claude to request and receive structured JSON objects (e.g., `{video_id, outlier_score, transcript, hook_type}`) instead of free‑form text, which improves the model’s reasoning accuracy.  
- **Three‑Step Content Workflow** – (1) Retrieve top‑performing clips, (2) extract recurring signals (hook, length, topic), (3) ask Claude to synthesize a set of new video concepts that embed those signals, ensuring each idea is grounded in observed data.

## 5. Tools & Technologies Mentioned  

- **Sandcastles (sandcastles.ai)** – A SaaS platform that aggregates short‑form video data, computes outlier scores, and provides full transcripts with hook/format annotations. It also hosts the MCP endpoint used by Claude.  
- **Claude (claude.ai, Claude Desktop, mobile app)** – Anthropic’s conversational LLM, capable of ingesting structured JSON via connectors and performing higher‑order analysis (pattern detection, content ideation).  
- **MCP (Message‑Connector‑Protocol)** – The integration layer that authenticates via OAuth and streams data from Sandcastles into Claude sessions, exposing a live data bridge without manual export/import steps.  

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Competitor Benchmark & Content Gap Identification  
1. **Create a Sandcastles account** and start the 7‑day trial.  
2. **Add competitor channels** to a new watchlist (e.g., top creators in the “DIY home décor” niche).  
3. **Authorize the Sandcastles MCP connector** inside Claude’s Settings → Connectors → OAuth flow.  
4. In a Claude chat, type a prompt such as:  
   ```
   Pull the top 10 outlier videos from the watchlist “DIY Home Décor” for the past 30 days. Summarize the dominant hook types, video lengths, and recurring topics.
   ```  
5. Claude returns a concise table of hooks (e.g., “quick transformation reveal”), average length (≈15 s), and a list of under‑served topics.  
6. **Export the table** (or copy‑paste) and feed it back to Claude:  
   ```
   Generate 8 video ideas for my channel that use the “quick transformation reveal” hook but focus on the missing topics you identified.
   ```  
7. Review the generated ideas, prioritize, and schedule production.

### Use Case 2 – Self‑Channel Optimization & Repurposing  
1. **Add your own channel** to the Sandcastles watchlist.  
2. **Run a 40‑day recap** via Claude:  
   ```
   Analyze my channel’s last 40 days. List the top 5 outlier videos, explain why they succeeded, and suggest which of my lower‑performing videos could be re‑edited using the same hook.
   ```  
3. Claude highlights, for example, that “first‑second surprise reveal” hooks drove 2× higher retention.  
4. **Create a remake plan**: ask Claude to draft a script outline for each identified low‑performing video, swapping the original hook for the high‑performing one.  
5. Use Sandcastles’ built‑in **Hook Engine** to generate alternative opening lines, then feed those into Claude for polishing.  
6. Publish the revamped videos and monitor the uplift in engagement metrics.
