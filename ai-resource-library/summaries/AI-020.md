## 1. What This Resource Teaches  
This guide walks a newcomer through constructing an automated job‑search assistant that couples the **Indeed** job‑board API with **Claude** (Anthropic’s conversational model). The core idea is to let Claude act as a live data‑ingestion layer: it authenticates to an Indeed account, pulls the most recent postings, and then cross‑references those listings against the candidate’s résumé.  

The workflow is broken into six logical phases: (1) establishing a read‑only connector between Claude and Indeed, (2) uploading a digital CV so Claude can parse experience and skill tokens, (3) issuing a structured prompt that asks Claude to retrieve the top‑paying matches, (4) iteratively tightening the result set with salary, location, or skill constraints, (5) generating a role‑specific version of the CV that mirrors the language of the posting, and (6) repeating the tailoring step for each opportunity. The guide also supplies a library of reusable prompts for searching, filtering, CV rewriting, and cover‑letter drafting.  

Underlying the process is a simple architectural pattern: **Claude ↔ Indeed connector** (read‑only) → **Claude’s LLM engine** (semantic matching, keyword extraction, text generation) → **User‑facing output** (ranked job list, customized CV). The model never writes or posts applications; it only supplies data for the user to act upon, preserving privacy and compliance.

## 2. Why It Matters  
Traditional job hunting is time‑intensive: scrolling through pages, manually copying listings, and re‑writing CVs for each role. By automating the discovery and personalization steps, the Claude‑Indeed integration reduces the average time‑to‑apply by an estimated 70‑80 %, allowing candidates to focus on interview preparation and networking.  

From a strategic perspective, the workflow demonstrates how LLMs can be leveraged as **semantic filters** over live data streams, a pattern that extends beyond recruiting to any scenario where a user needs to match a personal profile against a constantly updating catalogue (e.g., sales lead scoring, grant‑proposal matching). The approach also showcases a low‑code “connector” model that can be replicated for other job boards or SaaS APIs, making it a reusable blueprint for AI‑augmented productivity pipelines.

## 4. Key Concepts & Principles  

- **Connector‑Based Data Access**: A lightweight, read‑only bridge that authenticates Claude to an external service (Indeed) and streams live records into the LLM’s context.  
- **Semantic Resume Parsing**: Claude extracts entities (job titles, technologies, years of experience) from the uploaded CV, turning an unstructured PDF/Word file into a searchable skill vector.  
- **Prompt‑Driven Retrieval & Ranking**: By phrasing the request as “find the highest‑paying jobs that match my experience,” Claude performs a dual operation—filtering raw listings and scoring them against the parsed résumé.  
- **Iterative Constraint Refinement**: Users can tighten the search space (salary floor, remote‑only, technology exclusions) and re‑invoke the connector, enabling a feedback loop that converges on the most relevant opportunities.  
- **Keyword‑Aligned CV Generation**: Claude rewrites the original résumé to echo the exact terminology used in a target posting, improving ATS (Applicant Tracking System) compatibility without fabricating experience.

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Automated High‑Pay Role Discovery  
1. **Configure the connector**: In Claude’s settings, locate the “Connectors” panel, select Indeed, and complete OAuth‑style authorization (grant read‑only access).  
2. **Upload the résumé**: Start a fresh conversation, attach the PDF/Word file, and let Claude confirm successful ingestion.  
3. **Issue the search prompt**:  
   ```
   Using my uploaded CV, query Indeed for the top 10 highest‑salary positions that align with my background. Return title, company, salary, and a brief justification for each match.
   ```  
4. **Review the ranked list**: Claude returns a table‑style output; note the salary figures and matching rationale.  

### Use Case 2 – Role‑Specific CV Tailoring  
1. **Select a target posting**: Copy the URL or paste the full job description of a role from the previous list.  
2. **Prompt Claude for a rewrite**:  
   ```
   Combine my original CV with the following job description. Produce a revised CV that foregrounds the most relevant experience, mirrors the posting’s keywords, and remains factually accurate.
   ```  
3. **Validate the output**: Manually scan the generated CV for any inadvertent exaggerations; adjust as needed.  
4. **Export**: Download the tailored CV (Claude typically offers a “download” button or you can copy‑paste into a document editor).  

Both workflows can be looped: after tailoring one CV, return to the conversation, keep the original résumé in context, and repeat for the next posting.
