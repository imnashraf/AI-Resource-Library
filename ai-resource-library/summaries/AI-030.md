## 1. What This Resource Teaches  
This guide walks a novice through the end‑to‑end process of turning Claude Code into a turnkey marketing engine. It starts with acquiring a curated collection of “skill” directories from a public GitHub repository, then shows how to embed those assets inside a local project folder that also houses brand‑specific collateral (logos, style guides, tone‑of‑voice documents). Once the folder is prepared, the user launches Claude Code from that directory, enabling the model to auto‑load the skill modules. The final steps verify that the modules are recognized and demonstrate a concrete task—generating a three‑email cold‑outreach sequence that references the brand assets.  

Underlying the tutorial is a simple architectural pattern: **file‑system‑driven plugin discovery**. Each sub‑folder (e.g., `ad-creative`, `cold-email`, `ai‑seo`) contains prompts, templates, or configuration files that Claude Code reads at runtime. By placing the folder on the local disk and invoking Claude Code from within it, the model treats the collection as a self‑contained knowledge base, eliminating the need for external API calls or manual prompt engineering for each marketing function.  

The resource also enumerates the breadth of capabilities that become instantly available—ad copy generation, SEO‑optimized content, competitor positioning, A/B test scaffolding, and full‑funnel launch planning—illustrating how a single, lightweight setup can replace a suite of disparate SaaS tools.

## 2. Why It Matters  
In modern AI‑augmented marketing, teams often juggle multiple cloud services, each with its own pricing, integration overhead, and learning curve. This guide demonstrates a **cost‑effective, offline‑first alternative** that consolidates a wide range of marketing functions into a single, locally run LLM environment. By leveraging Claude Code’s native ability to ingest file‑based skill definitions, organizations can:  

* **Accelerate prototyping** – generate copy, email sequences, and ad creatives in seconds without waiting for third‑party approvals.  
* **Maintain brand consistency** – the model directly accesses brand assets, reducing the risk of tone drift that plagues generic AI outputs.  
* **Control data residency** – all prompts and brand documents stay on the user’s machine, satisfying privacy or compliance constraints.  

The approach also scales: adding a new skill is as simple as dropping another folder into the project directory, making the system extensible for future marketing initiatives.

## 4. Key Concepts & Principles  

- **File‑System Plugin Architecture**: Claude Code scans the current working directory for specially named subfolders, each representing a discrete marketing capability. The presence of these folders automatically registers the associated prompts and templates.  
- **Brand Asset Injection**: By storing logos, style guides, and tone documents in a dedicated `brand-assets` directory, the model can reference concrete visual and linguistic cues, ensuring outputs align with corporate identity.  
- **Prompt Contextualization**: Effective results hinge on crafting prompts that explicitly point to the `brand-assets` folder and describe the target audience, channel, and constraints (e.g., word count). This reduces hallucination and improves relevance.  
- **Iterative Verification**: A two‑step sanity check—first confirming that Claude Code lists the loaded skills, then running a test task—guarantees that the environment is correctly configured before production use.

## 5. Tools & Technologies Mentioned  

- **Claude Code**: A locally executable version of Anthropic’s Claude model that can read skill files from the filesystem. It is launched via a terminal command (`claude`) and serves as the central inference engine.  
- **GitHub (repo by Corey Haines)**: Hosts the open‑source collection of marketing skill folders. Users download the ZIP, extract only the `skills` directory, and integrate it into their project.

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Rapid Cold‑Email Campaign Generation  
1. **Prepare brand assets** – place logo, brand guide, and tone examples in `brand-assets`.  
2. **Launch Claude Code** from the project root (`cd path/to/project && claude`).  
3. **Confirm skill loading** by asking Claude to enumerate available modules.  
4. **Issue a targeted prompt**: request a three‑email sequence for UK small‑business owners unfamiliar with AI automation, specifying length and call‑to‑action.  
5. **Review output** – ensure the copy references brand language and includes a clear next step.  
6. **Export** the generated emails to a CSV or directly paste into an email platform.  

### Use Case 2 – End‑to‑End Content Strategy & SEO Production  
1. **Populate `brand-assets`** with existing blog posts, keyword lists, and SEO guidelines.  
2. **Run the `content-strategy` skill** by prompting Claude to devise a 90‑day editorial calendar for LinkedIn, blog, and newsletter.  
3. **Iterate**: ask Claude to flesh out each topic into an SEO‑optimized outline using the `ai‑seo` skill.  
4. **Generate full articles** by feeding the outlines back into Claude, requesting a specific word count and meta description.  
5. **Export** the finished copy to a content management system (CMS) or markdown files for later publishing.  

Both workflows emphasize **context‑rich prompting** and **file‑based skill activation**, allowing marketers to stay within a single interface throughout the creative process.
