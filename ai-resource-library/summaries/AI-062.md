## 1. What This Resource Teaches  
The guide presents a collection of ten ready‑made AI‑driven routines that can be scheduled to run automatically each week. Each routine is built around a single, reusable prompt that is paired with a cadence (hourly, daily, weekly, or monthly). The core learning objective is to show how to turn repetitive, time‑consuming tasks—such as inbox triage, meeting prep, content repurposing, and financial bookkeeping—into unattended, clock‑driven workflows that deliver finished work directly to the user’s inbox, Drive folders, or task lists.

Technically, the resource explains how to configure the two major AI platforms—Anthropic’s Claude (via the Cowork interface) and OpenAI’s ChatGPT (via the Scheduled Tasks feature)—to run these prompts. It covers the necessary connectors (Gmail, Google Calendar, Google Drive), the approval modes (draft‑only vs. fully automated), and the limitations of each platform (e.g., no event triggers, no local file access for cloud tasks). By following the step‑by‑step prompts, readers learn how to structure prompts that filter, summarize, and transform data from email, calendar, and Drive into actionable outputs such as draft replies, meeting briefs, task lists, and content hooks.

Architecturally, the guide demonstrates a modular approach: each automation is a stateless function that reads from a source, processes the data, and writes the result to a destination. This pattern encourages reuse, easy debugging, and incremental scaling—starting with one automation, validating its output, and then adding the next.

## 2. Why It Matters  
In a world where professionals juggle dozens of emails, meetings, and content calendars, the ability to offload routine cognitive load is a competitive advantage. Automating the “low‑value” parts of a week frees up mental bandwidth for strategic decision‑making, creative work, and high‑impact interactions. The guide’s emphasis on scheduled, clock‑driven tasks sidesteps the complexity of event‑based triggers, making the setup approachable for users who may not have coding experience. By integrating with familiar tools (Gmail, Calendar, Drive) and leveraging AI’s natural‑language understanding, the automations reduce manual effort by 30–70 % for many of the listed activities. Moreover, the modular design allows teams to adopt a single automation at a time, monitor its reliability, and then expand the automation ecosystem without disrupting existing workflows.

## 4. Key Concepts & Principles  
- **Scheduled (Clock‑Based) Automation**: Tasks run on a fixed cadence rather than in response to events, simplifying configuration and ensuring reliability across platforms.  
- **Connector‑Driven Data Flow**: Gmail, Calendar, and Drive act as the primary data sources and sinks; the AI prompt orchestrates extraction, transformation, and loading.  
- **Approval Mode Management**: Starting in “draft‑only” mode mitigates risk; once confidence is established, the task can be switched to fully unattended.  
- **Local vs. Cloud Task Distinction**: Cloud tasks cannot access local file systems; any cleanup or file‑system manipulation must be performed by a local routine that runs while the machine is awake.  
- **Incremental Adoption**: Deploy one automation, observe three successful runs, then add the next—this reduces the chance of cascading failures and eases troubleshooting.

## 6. Practical Use Cases & Workflows  
- **Inbox Triage & Draft Replies**  
  1. Configure a weekday 7 AM scheduled task that pulls all emails received since 5 PM the previous day.  
  2. Prompt the AI to classify messages into HIGH, MEDIUM, and LOW buckets.  
  3. For HIGH/MEDIUM items with low‑risk answers, the AI writes draft replies directly into the user’s Gmail drafts.  
  4. The user reviews the drafts once per day, reducing morning email handling time by up to 50 %.  

- **Pre‑Meeting Dossier**  
  1. Set an hourly task that scans the user’s Calendar for meetings starting within the next 90 minutes.  
  2. For each external attendee, the AI searches the web for recent news, company data, and past email interactions.  
  3. The AI compiles a one‑page briefing (overview, company snapshot, talking points, questions, desired outcome).  
  4. The briefing is delivered via email or a shared Drive file, ensuring the user arrives prepared without manual research.  

## 7. Prerequisites  
- **Paid AI Plan**: Claude Pro/Team/Enterprise or ChatGPT Plus/Pro/Business/Enterprise to enable scheduled tasks.  
- **Google Account with API Access**: Gmail, Calendar, and Drive connectors must be authorized; each connector is toggled separately.  
- **Folder Structure in Drive**: Create empty folders such as `/Meetings/Transcripts`, `/Content/LongForm`, `/Finance/Receipts`, and `/Content/Analytics` before building automations that rely on them.  
- **Optional Task Connector**: If you want meeting actions to appear in a task list, connect a task‑management app (e.g., Todoist, Notion).  
- **Local Runtime (if needed)**: For desktop cleanup, install Claude Code or the ChatGPT desktop app and keep it running on a Friday evening.
