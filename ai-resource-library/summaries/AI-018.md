## 1. What This Resource Teaches  
This guide walks the reader through constructing a closed‑loop research pipeline that blends Google’s NotebookLM knowledge base with Anthropic’s Claude Code development environment. By installing the community‑maintained `notebooklm-py` package, users gain programmatic, scriptable access to the content stored in NotebookLM notebooks—capabilities that the native web UI does not expose. The tutorial then shows how to package that access as a Claude Code “skill,” enabling the LLM to fetch and reason over notebook data directly from the terminal without manual copy‑pasting.

The core workflow revolves around three purpose‑built notebooks that act as autonomous “research agents”:  

1. **Role‑Model Agent** – a repository of external thought leaders, interviews, and published material.  
2. **Self Agent** – a personal archive of the user’s own strategic documents, notes, and recordings.  
3. **Business Agent** – a market‑focused collection containing competitor intel, industry reports, and product documentation.  

Once the agents are populated, a single weekly prompt is executed inside Claude Code. The prompt simultaneously queries all three agents, asks each to surface gaps relative to the user’s current activities, and then asks Claude to synthesize the top three actionable priorities for the coming week. The result is a repeatable, data‑driven reflection loop that surfaces blind spots that would otherwise emerge only after months of ad‑hoc analysis.

## 2. Why It Matters  
Integrating NotebookLM with Claude Code creates a “knowledge‑augmented IDE” where the LLM can draw on a curated, private knowledge graph at runtime. This eliminates the friction of manually feeding context into prompts, dramatically reducing prompt length and token waste while increasing relevance. The three‑agent pattern enforces multi‑perspective thinking: external best‑practice (role model), internal consistency (self), and market reality (business). By automating the weekly synthesis, founders, product managers, or researchers can institutionalize strategic alignment, accelerate decision‑making, and catch drift before it compounds. In a landscape where AI‑assisted productivity tools are proliferating, this integration offers a low‑cost, open‑source method to embed a personal “strategic advisor” directly into the development workflow.

## 4. Key Concepts & Principles  

- **Programmatic Notebook Access**: Leveraging `notebooklm-py` to automate Google session authentication and retrieve notebook contents via a Python API, bypassing the need for an official Google API key.  
- **Claude Code Skill Architecture**: Packaging the NotebookLM client as a Claude Code plugin (skill) placed in a `.claude-plugin` directory, allowing Claude to invoke notebook queries as native commands.  
- **Agent‑Based Knowledge Segmentation**: Structuring distinct notebooks around external role models, personal artifacts, and market data to enforce perspective diversity and reduce context contamination.  
- **Scheduled Prompt Orchestration**: Designing a single, repeatable prompt that simultaneously addresses all three agents, then asks Claude to prioritize insights, turning a weekly ritual into a deterministic output pipeline.

## 5. Tools & Technologies Mentioned  

- **notebooklm-py** – an unofficial Python wrapper that automates a Google login flow and exposes NotebookLM notebook CRUD operations. Used to bridge NotebookLM data into Claude Code.  
- **Claude Code** – Anthropic’s code‑centric LLM interface that supports extensible “skills” (plugins) for custom command execution. Serves as the execution environment for the weekly synthesis prompt.  
- **Python 3.10+** – Required runtime for `notebooklm-py`.  
- **pip** – Python package manager used to install the `notebooklm` library.  
- **git** – Version‑control client employed to clone the repository containing the Claude skill.  

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Setting Up the Knowledge Bridge  
1. **Install the API client**:  
   ```bash
   pip install notebooklm
   ```  
2. **Authenticate to Google** (opens a browser for OAuth):  
   ```bash
   notebooklm auth login
   ```  
   The resulting session token is cached locally for subsequent calls.  
3. **Clone the repository** that ships the Claude skill:  
   ```bash
   git clone https://github.com/teng-lin/notebooklm-py.git
   ```  
4. **Create the plugin directory** (if absent) and copy the skill:  
   ```bash
   mkdir -p ./my-project/.claude-plugin
   cp -r notebooklm-py/skills/notebooklm ./my-project/.claude-plugin/
   ```  
5. **Restart Claude Code** so it discovers the new skill.  

### Use Case 2 – Weekly Insight Generation  
1. **Populate the three notebooks** in NotebookLM:  
   - *Role Model*: upload PDFs, URLs, or transcripts of thought leaders.  
   - *Self*: add internal strategy docs, meeting notes, and voice‑to‑text logs.  
   - *Business*: ingest competitor site snapshots, market research PDFs, and product specs.  
2. **Open Claude Code** and paste the following prompt (or store it as a snippet for reuse):  

   ```
   Query the three research agents:
   - Role Model: Identify actions this person would take that differ from my current approach.
   - Self: Highlight where my recent decisions diverge from my stated strategy.
   - Business: Surface competitor moves or market signals I have missed.
   Synthesize the responses and list the top three priorities for this week.
   ```  

3. **Execute the prompt** (typically Monday morning). Claude will call the NotebookLM skill, retrieve relevant excerpts, and return a concise priority list.  
4. **Iterate**: Add new documents to each notebook throughout the week to improve future outputs.
