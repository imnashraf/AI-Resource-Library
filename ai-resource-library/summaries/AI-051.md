## 1. What This Resource Teaches  
This guide shows how to replace a traditional Meta advertising team with a single Claude conversation by chaining together five custom “skills” that tap into Meta’s public and private data layers. The core learning path is:  

1. **Set up the foundation** – enable Model Context Protocol (MCP) in Claude, install Node‑based MCP servers, and secure a Meta system‑user token.  
2. **Connect to Meta** – run two MCP servers: one that pulls the public Ad Library (no auth) and another that pulls your own account data via the Marketing API.  
3. **Deploy five autonomous skills** – each skill performs a distinct function:  
   * **Spy** – harvests competitors’ active creatives.  
   * **Bulk Creative** – turns that data into ten fresh ad scripts.  
   * **Ad Score** – evaluates your recent creatives against weighted performance metrics.  
   * **Competitive Extractor** – dissects competitor ads into structural patterns.  
   * **Ads Meta** – stitches the outputs into a concise weekly brief.  
4. **Adopt a repeatable rhythm** – run the skills in a fixed order every week to generate a competitive intelligence snapshot, creative ideas, performance insights, and a strategic brief—all in under 30 minutes.  

The architecture relies on MCP’s ability to expose live API data to Claude, turning the LLM into a real‑time decision engine that can read, generate, and score Meta ads without leaving the chat.

## 2. Why It Matters  
- **Speed & Scale** – A single conversation can replace a multi‑person team that would otherwise spend hours on research, copywriting, and analysis.  
- **Data‑Driven Creativity** – By feeding Claude with structured competitor data and your own performance metrics, the system surfaces proven patterns and flags under‑performing creatives automatically.  
- **Cost Efficiency** – The weekly cadence keeps spend in check: you only test the top three concepts that the system recommends, avoiding a flood of untested ads.  
- **Unified Workflow** – All steps—from intelligence gathering to brief generation—are executed in one place, reducing context switching and documentation overhead.  
- **Future‑Proofing** – The MCP framework is agnostic to other APIs, so the same pattern can be extended to TikTok, Google Ads, or any platform that offers a public library and a private API.

## 4. Key Concepts & Principles  
- **Model Context Protocol (MCP)**: A protocol that lets Claude fetch live data from external services, turning the LLM into a real‑time data consumer.  
- **Dual MCP Layers**:  
  * *Public Layer* – reads the Meta Ad Library (no auth).  
  * *Private Layer* – reads your own account via the Marketing API (requires a system‑user token).  
- **Skill Orchestration**: Each skill consumes the output of previous skills, creating a data pipeline that flows from competitor research to creative generation to performance scoring.  
- **Weighted Performance Scoring**: The Ad Score skill applies configurable weights (hook rate, CTR, thumb‑stop, ROAS, CPM) to produce a single score that drives scaling decisions.

## 5. Tools & Technologies Mentioned  
- **Claude Pro / Team** – The LLM platform that hosts the skills and MCP connections.  
- **Node.js (≥18)** – Runtime for the MCP servers that bridge Claude to Meta APIs.  
- **Meta Marketing API** – Provides access to ad spend, ROAS, CPM, CTR, and creative details.  
- **Meta Ad Library API** – Public endpoint for scraping active ads.  
- **MCP Servers (`meta-ad-library`, `meta-ads-manager`)** – Node packages that expose the two MCP layers to Claude.  
- **Environment Variables (`META_ADS_TOKEN`)** – Securely store the system‑user token used by the private MCP layer.  
- **Claude Skills** – Custom LLM prompts that implement the five core functions.

## 6. Practical Use Cases & Workflows  
- **Use Case 1 – Weekly Creative Sprint**  
  1. **Monday** – Run `/spy` to pull all active competitor ads.  
  2. **Immediately after** – Run `/extract` on the top three brands to get structural patterns.  
  3. **Next** – Run `/bulk-creative` to generate ten fresh ad scripts, automatically ingesting the spy data and extraction.  
  4. **Later** – Run `/score` to evaluate last week’s creatives and flag scaling or pausing actions.  
  5. **End of the week** – Run `/meta-brief` to produce a concise brief: top competitor patterns, best internal angles, and five recommended tests.  

- **Use Case 2 – Monthly Strategy Reset**  
  1. On the final Monday of the month, run `/meta-brief --monthly`.  
  2. The skill outputs a 30‑day retrospective, highlights trends, and lays out a four‑week testing calendar for the next month.  
  3. Use the brief to realign budgets, refresh creative themes, and adjust scoring weights if business priorities shift.

## 7. Prerequisites  
- **Claude Pro or Team subscription** (free tier lacks extended context and skill installation).  
- **MCP enabled** in Claude settings (`Settings → Developer → Model Context Protocol`).  
- **Node.js 18+** installed (`node -v`).  
- **Meta Business Manager access** with admin or advertiser rights on the target ad accounts.  
- **Meta system‑user token** with `ads_read` permission, stored as `META_ADS_TOKEN`.  
- **Basic familiarity with command‑line operations** (npm, environment variables).
