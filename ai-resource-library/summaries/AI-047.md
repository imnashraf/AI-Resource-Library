## 1. What This Resource Teaches  
This guide explains how to leverage Anthropic’s **Claude Design** canvas to produce Instagram carousel decks that feel handcrafted rather than mass‑produced by a language model. The core workflow collapses three high‑level inputs—**topic**, **visual style**, and **brand identity**—into a single prompt that drives the model to generate a complete, editable slide set, complete with layout, typography, and colour palette.  

Beyond the initial generation, the article details a refinement loop where designers issue concise, slide‑level edit commands (e.g., “increase headline weight on slide 3”) and then export the finished assets to downstream tools such as **Canva**, PDF, or PNG. It also surfaces the common visual “tells” that betray AI‑generated carousels (default system fonts, uniform grids, purple‑to‑cyan gradients, etc.) and shows how to neutralize them by swapping vague adjectives for concrete references.  

Underlying the process is the **Opus 4.7 vision model**, which powers Claude Design’s ability to interpret both textual prompts and image references, allowing the system to mimic a specific design language rather than defaulting to a median aesthetic.

## 2. Why It Matters  
In fast‑moving social‑media marketing, the time saved by automating slide layout can be the difference between a daily posting cadence and a stagnant feed. By feeding Claude Design a tightly scoped brief and a real‑world visual reference, creators can cut the manual layout phase from hours to roughly ten‑minute drafts, then spend a few minutes polishing. This dramatically reduces the cost of content production while preserving brand distinctiveness—something generic AI outputs have historically failed to achieve.  

Strategically, the method integrates AI into the *design* stage rather than relegating it to copy‑only generation, expanding the scope of AI‑assisted creativity. Teams that adopt this workflow can scale carousel output, maintain visual consistency across campaigns, and free senior designers to focus on higher‑order strategy instead of repetitive slide assembly.

## 4. Key Concepts & Principles  

- **Topic‑Plus‑Style Prompting** – Instead of vague descriptors (“clean, modern”), the workflow demands a narrow, outcome‑driven topic and a concrete visual reference (e.g., “Swiss typographic poster”). This eliminates the model’s tendency to converge on a bland median.  

- **Design Tells & Their Suppression** – Six visual cues (default system fonts, grid‑only layouts, purple‑to‑cyan gradients, perfect symmetry, lack of narrative flow, generic iconography) are identified as red flags for AI‑generated work. Explicitly banning these elements in the prompt forces the model to deviate from the default.  

- **Slide‑Level Refinement Language** – After the first canvas is generated, designers issue short, imperative edit commands that target a single slide or a global attribute (e.g., “swap accent colour to #35C4A2”). Claude Design respects these micro‑edits without re‑rendering the entire deck.  

- **Brand System Integration** – By supplying a brand handle, margin rules, type scale, and colour palette, the model can produce a cohesive set that feels like a single designer’s hand, preserving brand equity across all slides.  

## 5. Tools & Technologies Mentioned  

- **Claude Design (Anthropic)** – A canvas‑based design assistant that combines a large‑vision model with an interactive UI. Users input a structured prompt, receive a full carousel layout, and can edit elements directly on the canvas.  

- **Canva** – Used as the downstream editor for final polishing and export. Claude Design can push the generated slides into Canva as fully editable layers, allowing designers to tweak details that the AI may have missed.  

- **Opus 4.7 Vision Model** – The underlying model that enables image‑aware prompting, allowing Claude Design to ingest a screenshot of a reference carousel and replicate its visual language.  

## 6. Practical Use Cases & Workflows  

### Use Case 1 – Weekly Real‑Estate Tips Carousel  
1. **Define the narrow topic**: “5 ChatGPT prompts that let real‑estate agents save an hour each day.”  
2. **Select a visual reference**: Screenshot of a high‑end real‑estate magazine spread.  
3. **Gather brand assets**: Helvetica Neue for body, a custom display font for headlines, palette #1A202C, #F5A623, #E2E8F0, and the @reagenthandle logo placement.  
4. **Paste the Full Carousel Prompt** into Claude Design, swapping bracketed placeholders.  
5. **Review the auto‑generated 7‑slide deck**; use slide‑level edit commands such as “increase headline weight on slide 3” and “replace background on slide 5 with #E2E8F0.”  
6. **Export to Canva**, make any final typographic tweaks, then download as PNG for Instagram.  

### Use Case 2 – Internal Product Feature Announcement  
1. **Topic**: “New AI‑driven analytics dashboard reduces reporting time by 40% for product managers.”  
2. **Style reference**: A fintech UI kit with bold data visualizations.  
3. **Brand**: Company’s design system (type: Inter UI for body, Gotham Bold for headings; colours: #0A0A0A, #00BFA5, #FFFFFF).  
4. **Prompt**: Use the quick version for a 5‑slide carousel, specifying the hook (“Cut reporting time by 40%”) and CTA (“Try the dashboard now”).  
5. **Generate**, then refine: “Swap the icon on slide 2 for a line‑chart illustration,” “align the CTA button to the bottom right on slide 5.”  
6. **Export as PDF** for internal email distribution, or as PNG for Slack posting.  

## 7. Prerequisites  

- Active **Claude Design** subscription (Pro, Max, Team, or Enterprise).  
- Access to the brand’s font files or web‑font URLs (to avoid silent fallback to system fonts).  
- A clear, outcome‑focused carousel topic and a high‑resolution visual reference (screenshot or image file).  
- Basic familiarity with Canva or another graphics editor for final polishing.
