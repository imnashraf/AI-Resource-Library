## 1. What This Resource Teaches
This guide outlines a strategic pathway for transitioning from individual AI user to "Agent Manager," a role focused on orchestrating fleets of autonomous AI agents rather than building them from scratch. It posits that the core competency of this role is not coding, but rather the ability to define clear boundaries, manage inter-agent collaboration, and enforce human oversight. The curriculum emphasizes that while the theoretical frameworks are freely available, the differentiator for employment is the creation of tangible proof-of-concept artifacts that demonstrate effective management of multi-agent systems.

The technical mechanics described involve constructing a simulated team of three distinct agents (Researcher, Drafter, and Executor) within the Claude ecosystem. Each agent is assigned specific permissions and hard limits to prevent overreach, mimicking a corporate hierarchy. The guide instructs users to implement an "approval gate," a mandatory human checkpoint that prevents any agent from executing final actions without explicit sign-off. This architecture is designed to demonstrate safety, accountability, and structured workflow management, which are critical concerns for enterprise adoption of AI.

Finally, the resource teaches a rigorous evaluation methodology. Users are instructed to run a real-world task through this agent team, intentionally introducing a rejection or correction to test the system's resilience. The output of this process is a "scorecard"—a one-page analytical document that grades the agents on task completion, adherence to limits, error handling, and log clarity. This scorecard serves as the primary portfolio piece for job interviews, proving the candidate can manage AI operations effectively.

## 4. Key Concepts & Principles
- **Orchestration vs. Prompting**: The distinction between simply asking an AI for an answer (prompting) and coordinating multiple specialized agents to achieve a complex goal (orchestration). Orchestration involves defining roles, managing handoffs, and ensuring the collective output exceeds the sum of individual parts.
- **Hard Limits & Permission Boundaries**: The principle that each agent must have explicitly defined, specific constraints on what it can access, create, or send. Vague instructions like "be responsible" are insufficient; limits must be technical and enforceable (e.g., "can draft but cannot send").
- **Human-in-the-Loop (HITL) Approval Gates**: A critical safety mechanism where a human must review and approve an agent's output before it is executed or published. This ensures accountability and prevents autonomous errors from becoming irreversible actions.
- **The Scorecard Artifact**: A standardized evaluation document that grades agent performance on specific criteria (completion, limit adherence, error handling, log clarity). This transforms raw session data into a professional portfolio piece that demonstrates managerial competence.

## 6. Practical Use Cases & Workflows
- **Building a Managed Agent Team**:
    1.  **Define Roles**: Create three distinct agents in Claude: a Researcher (gathers info, no sending), a Drafter (creates output, no approval), and an Executor (acts only after approval).
    2.  **Set Hard Limits**: Configure each agent with specific permissions. For example, the Researcher can browse and summarize but cannot publish. The Executor cannot act without a human sign-off.
    3.  **Implement Approval Gate**: Insert a mandatory step where the human reviews the Drafter’s output. The Executor is only triggered if the human approves.
    4.  **Execute Task**: Run a real-world job (e.g., drafting a client proposal) through this pipeline.
    5.  **Introduce Error**: Deliberately reject the output once to test how the agents handle correction and rework.
    6.  **Grade & Document**: Review the session log and create a one-page scorecard evaluating each agent against the four key criteria.

- **Preparing for an Agent Manager Interview**:
    1.  **Complete Theory**: Finish the three Anthropic Academy courses to gain foundational vocabulary and concepts.
    2.  **Create Proof**: Build the three-agent team and run the evaluation workflow described above.
    3.  **Refine Vocabulary**: Ensure you can accurately define terms like "orchestration," "handoff," and "approval gate" in the context of your build.
    4.  **Present Artifact**: Bring the scorecard and session log to the interview as tangible evidence of your ability to manage AI agents safely and effectively.
